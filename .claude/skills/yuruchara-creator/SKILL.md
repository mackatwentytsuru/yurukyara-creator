# ゆるキャラクリエイターの段取り

作業場所は `creator/`、置き場は手元の作業フォルダ(重い物はここ。リポジトリに入れない)。各段の道具は `creator/README.md` の表。


## 確認が出る時(先に 1 行だけ言う)

確認(許可の画面)は、話すことや覚えたことが変わる時・PC の外を読む時・お金や長い時間を使う時・戻しにくい時・外へ出す時だけ出る。読む・下書き・点検・変わる所の表示・一覧・自分の試験では出ない(`.claude/settings.json` の決まり。全体は `docs/confirmations.md`)。
確認が出る道具の直前に、次の 1 行だけを言う。会話で別に「いい?」とは聞かない(同じことを 2 回聞かない)。

| する事 | 直前に言う 1 行 |
|---|---|
| 消す(`rm`) | 「<名前>を消します。ゴミ箱に入らず、戻せません。次に出る画面が、その確認です。」 |
| 外へ出す(`git push`・`gh`・`vercel`) | 「<どこ>へ出します。はい → ほかの人にも見えます。戻す → 取り下げ(すぐには消えません)。次に出る画面が、その確認です。」 |
| 話し方の文を手で直す(`persona.md`・`character.json`) | 「<名前>の話し方を書き換えます。先に前の版を creator/work に取っておきます。次に出る画面が、その確認です。」 |
| 守りの部品を変える(`.claude`・`tools`・`creator/learn`・`creator/pipeline`・`creator/review`・`creator/setup`・`web/src/conversation`) | 「この子を守る仕組みを変えます。ふつうは要りません。頼んだ覚えが無ければ『いいえ』を押してください。次に出る画面が、その確認です。」 |
| 作る画面を起こす | 「作る画面を起こします。同じ Wi-Fi のスマホからも開けます(合言葉つき)。止める → 窓を閉じる。次に出る画面が、その確認です。」 |
| 鍵 | 聞かずに止める: 「鍵はここに貼らないでください。画面の鍵の欄に入れてください。」 |

- 初めて作る人には、最初に 1 回だけ「頼んでいない確認が出たら『いいえ』を押してください」と言う。
- 確認で「いいえ」を選ばれたら、別の道具や書き方で同じことをしない。止まって、どうするかを聞く。

## 本命: 手組み(Blender の Python で一から)

1. 元の絵を開いて見る。画素から寸法を割り出す(体の幅 px ÷ 実寸、各部品の中心・幅・高さ)。色は画素を標本にとる。
2. `creator/builders/<id>.py` に部品を書く(`m00_prims`: superquadric=丸みのある箱・楕円体、ring=輪、cloth=布の板)。数字は上の辞書 D にまとめる。
3. `sh creator/pipeline/run_built.sh <id> <作業フォルダ> x` で 1 周(約 16 秒)。`s03_compare.py` で元の絵と並べ、数字(寸法・角の丸さ・色)を直す。輪郭の重なり(IoU)と、見た目の両方を見る。
4. 顔: led は `f01_face_atlas.py led`(40×40 の点、背景は体より暗い半透明、縁はなめらかに消える)、paper は `paper`(茶色の目と口、ほお)。
5. 色の濃淡は、頂点の色(`P.gradient`)で焼く。**glTF は手続きの節点(Layer Weight など)を書き出せない**(白く飛ぶ)。頂点の色か絵だけ。
6. 判定は作った担当とは別の文脈の Claude(Haiku 5.5 と Sonnet 5.5。`creator/pipeline/j01_judge.py`)。見た目の最後の確認は Opus。

## 仕上げ

- 確かめ: `b06_posecheck.py` + `s02_posesheet.py`(動きの姿勢)、`b05_render.py` + `s01_sheet.py`(8 方向)。**絵を開いて見る。** そのあと別の文脈の Claude に判定させる。詳しい手順は `hand-built-character` スキル。
- 渡す: `pk01_package.py` → `characters/<id>/`。ブラウザで `python creator/viewer/serve.py` を立て、確かめ画面で表情・口・動きを 1 つずつ確かめる。

## 見つけた落とし穴(直し方つき)

- Blender の OBJ 読み込みは、物を **180° 回して**入れる。重みや顔の面はファイルの座標で測るので、`b03_rig.py` は物の回転を 0 に戻している。戻さないと、腕が細長い刃のように伸びる。
- 骨の回転の軸は**世界の軸**で書く(`b04_motions.py`)。骨は全部「上向きの短い棒」。
- 腕の重みの境目は、胴の側面より**外**に置く。胴の側面に置くと、胴の側面が腕について動く。肩の支点は、腕の付け根(腕の高さの上のほう)に置く。
- 顔の面は、体の表面へ光線を当てて貼る。表面に凹凸があるキャラは `face.smooth_iter` でならし、`lift` を大きくする。
- glTF の絵は上が v=0。顔の表の行は `flipY` を見て選ぶ(`rigRuntime.js`)。
- numpy 2 には `ndarray.ptp()` がない(`np.ptp`)。
- 確かめ画面のサーバーは `creator/viewer/serve.py`(キャッシュなし)。ふつうの `http.server` だと、ブラウザが古い JS を使う。

- 顔の面で、光線が体に当たらなかった点(丸い角の外)を体の最前面に置くと、角が空中に浮いて、横から見ると白い棒に見える。いちばん近い当たった点の奥行きにそろえる(`b03_rig.py`)。
- 手をふる・おじぎの確かめは、振りの位相が逆の 2 コマ(`wave:17 wave:22`)を並べる。同じ位相の 2 コマだと差が読めない。
- 動きの一覧は、1 コマ 560px 以上、ふつうの画面(幅 400px)で読める大きさにする。
- 【11-06】判定を Claude だけ(Haiku 5.5 と Sonnet 5.5)にした。答えのファイル(`answers/*.txt`)が空・形が崩れた回は、理由を見て同じ決まりで流し直す(2 回まで)。**判定役を替えて合格にしない。** 2 つの判定役は同じ系統で独立した確認ではない。Sonnet 5.5 は毛足と部分を厳しく(34 束すべて「いいえ」)、Haiku は甘く出た。割れたら、両方はいでないものは数えず、そのまま書く。`claude -p` を呼ぶときは、親の `CLAUDE_CODE_` の環境変数を外す(`j01_judge.py` の `clean_env`)と、別の文脈で動く。1 束(判定 6 回)は約 40 秒、34 束を 8 並列で約 15 分。
- 【11-04】薄い部品(葉・マント・角)の縁に針のような毛が出る、頭と胴の境に水平の段ができる、が新しい題材 4 体で出た。同じ形の題材では、検査が通っても目で縁と境を見る。判定が通ることと、良く見えることは別。
- 【11-06】元の絵が無いときは、Claude が SVG で描く(`talking-character` の「絵が無いとき」)。光る点・紙の顔の位置と大きさは `creator/specs/<id>_face.args`(`run_built.sh` が `f01_face_atlas.py` に渡す)で元の絵に合わせる。`check_all.sh` のブラウザは、GPU の札を取ったあと `CHECK_GPU=1` で流す。`pk04_install.py` は顔の表(`face.atlas`)も置く。
