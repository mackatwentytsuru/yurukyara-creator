# ゆるキャラクリエイターの段取り

作業場所は `repo\creator\`、置き場は `work\creator_work\<id>\`(重い物はここ。リポジトリに入れない)。各段の道具は `creator/README.md` の表。

## 本命: 手組み(Blender の Python で一から)

1. 元の絵を開いて見る。画素から寸法を割り出す(体の幅 px ÷ 実寸、各部品の中心・幅・高さ)。色は画素を標本にとる。
2. `creator/builders/<id>.py` に部品を書く(`m00_prims`: superquadric=丸みのある箱・楕円体、ring=輪、cloth=布の板)。数字は上の辞書 D にまとめる。
3. `sh creator/pipeline/run_built.sh <id> <作業フォルダ> x` で 1 周(約 16 秒)。`s03_compare.py` で元の絵と並べ、数字(寸法・角の丸さ・色)を直す。輪郭の重なり(IoU)と、見た目の両方を見る。
4. 顔: led は `f01_face_atlas.py led`(40×40 の点、背景は体より暗い半透明、縁はなめらかに消える)、paper は `paper`(茶色の目と口、ほお)。
5. 色の濃淡は、頂点の色(`P.gradient`)で焼く。**glTF は手続きの節点(Layer Weight など)を書き出せない**(白く飛ぶ)。頂点の色か絵だけ。
6. 判定は作った担当以外(DeepSeek / GLM 5.3-flash)。見た目の最後の確認は Opus。

## AI の 3D 生成の道(比べ用)

## 段取り(Claude が各段の出来を見て、足りなければ前の段へ戻る)

1. **顔なしの絵**: 元の絵を Codex に渡し、目・口・光る点・ほおだけを消した同じ絵を作らせる(`codex_dual.py`。投げる前に `--dry-run`)。見る点: 体・手足・色・比率が元のまま。やり直しの目安: 余計な印が足されたら、プロンプトで「何も足さない」を強める。
2. **形**(GPU の札、1 回 1 時間以内): `p01_prep.py` で背景を抜き → `p03_trellis.py` で TRELLIS.2(1 視点で 9〜15 分)。**1 つの塊で足りた**(f_led・d_lantern)。腕・羽根が胴と離れすぎる、顔が崩れる形のときだけ、部品ごとに作る。
3. **整える**: `b01_mesh.py`(高さ・向き・面の数・UV)。細かい凹凸の多い形(提灯の骨)は `--smooth 3`、面は 40000〜60000。
4. **塗る**: `p05_paint.py`。正面・後ろ・横の「顔なしの絵」から塗る。単色のキャラは正面だけでよい(塗れない面は平均色で埋まる)。横と後ろが要るときは、Codex で同じ絵の横・後ろを作る。
5. **骨と重み**: `creator/specs/<id>.json` を書く(位置は外接箱に対する割合。先に `trimesh` で高さごとの横幅を測る)。`b03_rig.py`。
6. **顔の表**: `f01_face_atlas.py led|paper`。表情 5 + まばたき、口 4 段階。
7. **確かめ**: `b06_posecheck.py` + `s02_posesheet.py`(動きの姿勢)、`b05_render.py` + `s01_sheet.py`(8 方向)。**絵を開いて見る。** そのあと別の AI(`char-judge`)に判定させる。作った担当に自分の出来を判定させない。
8. **渡す**: `pk01_package.py` → `characters/<id>/`。ブラウザで `python creator/viewer/serve.py` を立て、確かめ画面で表情・口・動きを 1 つずつ動かす。

## 見つけた落とし穴(直し方つき)

- Blender の OBJ 読み込みは、物を **180° 回して**入れる。重みや顔の面はファイルの座標で測るので、`b03_rig.py` は物の回転を 0 に戻している。戻さないと、腕が細長い刃のように伸びる。
- 骨の回転の軸は**世界の軸**で書く(`b04_motions.py`)。骨は全部「上向きの短い棒」。
- 腕の重みの境目は、胴の側面より**外**に置く。胴の側面に置くと、胴の側面が腕について動く。肩の支点は、腕の付け根(腕の高さの上のほう)に置く。
- 顔の面は、体の表面へ光線を当てて貼る。表面に凹凸があるキャラは `face.smooth_iter` でならし、`lift` を大きくする。
- `trimesh` は OBJ の継ぎ目の UV を平均してしまう。`p05_paint.py` は OBJ を自分で読む。
- 塗れなかった島を Telea の穴埋めにすると筋が出る。押し引き(`push_pull`)で、届かない島は平均色で埋める。
- glTF の絵は上が v=0。顔の表の行は `flipY` を見て選ぶ(`rigRuntime.js`)。
- `p03_trellis.py`: 呼び出し元の `PYTHONHOME` などを子に渡さない(`SRE module mismatch`)。VRAM は 25GB 前後使う。札の申告は 20 以上。時間切れで落ちても居残らないよう、サンプリングのスレッドは daemon。
- numpy 2 には `ndarray.ptp()` がない(`np.ptp`)。
- 確かめ画面のサーバーは `creator/viewer/serve.py`(キャッシュなし)。ふつうの `http.server` だと、ブラウザが古い JS を使う。

- 顔の面で、光線が体に当たらなかった点(丸い角の外)を体の最前面に置くと、角が空中に浮いて、横から見ると白い棒に見える。いちばん近い当たった点の奥行きにそろえる(`b03_rig.py`)。
- 手をふる・おじぎの確かめは、振りの位相が逆の 2 コマ(`wave:17 wave:22`)を並べる。同じ位相の 2 コマだと差が読めない。
- 動きの一覧は、1 コマ 560px 以上、ふつうの画面(幅 400px)で読める大きさにする。
