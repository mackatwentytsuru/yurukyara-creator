# 読み上げの声を歌・掛け声にする(短い試し)

## 手順

1. 候補を 3 通り読ませる: 普通の文 / 音を伸ばしたかな(「ねえぇ〜」) / `[sings]` タグ付き。1 回の返事は 1 秒ほど、費用は文字数だけ。
2. 文字数の台帳を付ける。呼び出しの前に合計を足し、上限を超えるなら呼ばない。タグの文字も数える。失敗した呼び出しも数える。実装例: `show/audio/song_tts.py`(鍵は環境変数から読み、表示しない)。
3. 音程補正(ボーカロイド風): pyworld で f0・スペクトル・非周期性を取り、音声の区間(f0>0 が続く塊。0.12 秒以上の途切れで分ける)ごとに、フレームを補間して目標の長さに伸ばし、f0 を決めたメロディの音階に差し替えて合成する。実装例: `show/audio/song_make.py`。
   - 音の切り替えは 30 ms ほどの移動平均でなめらかにする(しないと音が跳ぶ)。
   - 子音(f0=0)はそのまま残す。残さないと聞き取れなくなる。
   - 音符は区間内を均等に割るだけなので、母音の途中で音が変わる。音節に合わせるなら音節の境界を別に取る必要がある。
4. 仮の伴奏は numpy だけで足りる: 4 つ打ちのキック(周波数の下がる正弦波)、ノイズのクラップとハット、正弦波のベース、加算合成のノコギリ波のコード。BPM 140 なら 1 拍 = 18900 サンプル(44.1 kHz)で割り切れ、拍に合わせやすい。
5. 掛け声は拍の位置(サンプル = 拍 × 18900)に置いて重ねる。曲を差し替えるときは伴奏だけ替える。
6. 仕上げ: ピークを -1 dB にそろえ、`ffmpeg -map_metadata -1` で mp3 にする。

## 測った事実(2026-11-02)

- eleven_v4_turbo は 30〜40 字で返事 1〜1.4 秒。`[sings]` を付けると同じ文で長さが 4.96 → 5.92 秒、f0 の中央値が 260 → 304 Hz に変わった(効いてはいる。歌に聞こえるかは耳で確かめる)。
- 伸ばしかな(「ぁ〜」「ぇ〜」)は有声部分がいちばん長く、補正の材料に向く。f0 の下限 81 Hz のような誤検出が出ることがある。
- venv は `python -m venv` → `pip install pyworld soundfile numpy` で入った(Windows、Python 3.10)。librosa 入りの別の環境には pyworld が無かった。
- 5 フレーズ・8.6 秒の補正と合成は CPU で 3.4 秒。

## 注意

- 歌に聞こえるかは AI には判定できない。耳で決める人に、候補を並べて渡す。
- 既存の曲の歌詞は使わない。
