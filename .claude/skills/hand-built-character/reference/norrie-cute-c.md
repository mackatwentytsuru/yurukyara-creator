# 主役ノリーを「思い切ってかわいく」した案 C(2026-11-07 夜、`creator/builders/norrie.py` の CUTE)

(元の文のまま)

奥さんの「3D がかわいくない」への 3 案のうちの C。絵の色・仮面・蝶ネクタイ・しっぽ・筋は同じで、赤ちゃんらしい頭身にした。
- **頭身は、組んだ後に物ごとに変形して変える**: 頭の物(頭・頭の殻・顔の板・目・口・前歯・歯ぐき・ほお)は首の骨 (0, −0.17, 0.60) のまわりに一様に 1.12 倍、ほか(胴・腕・足・蝶ネクタイ)は縦だけ 0.924 倍(耳の先 0.979 m を保つ式で決める)。頭と胴の比は 1.212。しっぽは変えない。シェイプキーのある物は `me.transform(M, shape_keys=True)`。
- 背中の筋・輪郭の殻・骨の位置は、変形の後に作る(筋が首で切れない)。頭の殻だけは口の穴の前に作るので、厚みを 1/1.12 で作る。骨の spec は builder が作業フォルダに書く(写しは `norrie_rig_c.json`)。
- **目**: 絵の直径の 1.6 倍(半径 25.4×27.8 px)、中心を 7 px 下(仮面の先の上)、ふくらみ 5 mm。目の行の顔の前を平らに寄せる(FACE_SHAPE の p を 1.2〜1.6)と目が前を向く。**光**は玉の前の面の点に、その点の法線の向きの薄い円板(白・発光、大 0.30・小 0.13 × 横の半径、見る人の左上と右下)を、目の物に合わせる。まばたきでは円板の真ん中へ縮める(白い線が残らない)。
- **ほお**: 仮面の上の桃色の楕円の板(244,192,198、面から 3.1 mm、`surface_only`)。
- **頭身を変えると、検査 ④(元の絵と比べた抜け)が落ちる所**: ① 耳を高くしたり、おでこを低くすると、全高を保つために頭のてっぺんが耳の先より下がり、絵のてっぺんが抜けた(770 px)。耳は幅だけ 1.12 倍・おでこは広げるだけにして 0。② 頭が大きく胴が短いと、あごの下と肩の間に絵に無いくぼみができた(左右 389・336 px)。あごを広げると手をふる腕が当たるので、袖の付け根の半径を 0.036 → 0.066 m(丸い肩)にして 0。
- **④ は CPU で先に見られる**: 全部の三角形を絵と同じ画素の枠(u = 568.5 + x·1040、v = 1076 − z·1040)で塗った輪郭を s05_gaps.py に通すと、GPU の m02 と同じ答え(770/508/455 px と 716/502/467 px)が数秒で出た。
- **めり込みも描かずに数える**: 動きを 2 コマおきに進め、骨で動かした形どうしの三角形の重なり(`BVHTree.overlap`)を数える(1 回 7 秒)。最初の版は、あごを前へ 40 px 出し下のほおを 24 px 広げたため、うなずき 74・おじぎ 62(あごと蝶ネクタイ)・手をふる 18(腕と下のほお)。あごを元の近くへ戻し、蝶ネクタイを 9 px 下げて 0(前のノリーも 0)。
- **C+眉(任意、NORRIE_BROWS=1、既定は眉なし)**: 目の上に黒い細い帯(ribbon)の眉を 2 本。brow_up・brow_sad は、同じ点の数の帯を高さ・傾きを変えて作り、頂点の位置をそのままシェイプキーに写す(並びが同じ)。表情への当てはめは character.json の写しで(happy 0.4・surprised 1.0 で上げ、sad で内の端を上げる)。寄りでは読めるが、スマホの大きさでは細い。
- **CPU だけの下見**: Cycles の CPU で、殻の材質を Backfacing で「表は黒・裏は透明」に替えると、ブラウザの「背面を描かない」に近い顔と全身が 4 枚 11 秒で撮れた(GPU の札待ちの間に形を決められた)。
- **新しいワークツリーでは、まず `creator/env.local.sh`(リポジトリに入れない)を写す**。無いと check_all の Blender が PATH の `blender` になり、③ は何も数えずに OK、④ は撮影が無くて落ちた。
- 頭の幅は「差が 12 より大きい画素の、目の高さの行の左端〜右端」で測る。目から続く区間だけを数えると、頭の影の側が背景に近い所で切れて小さく出た(今のノリーで 171 px、本当は約 400 px)。

## 案 C を判定のとおりに直した記録(2026-11-07 夜、NC1、`creator/builders/norrie.py`・`creator/pipeline/b04_motions.py`)
判定役 3 人(かわいさ・同じキャラか・傷)の指摘 7 つを、本物のアプリ(GPU の Chrome)で直した。
- **眉なしの「困り顔・泣きそう」の正体**: 目の玉の軸を頭の面の横向き(約 12°)に合わせていたので、正面で目の外の端が下がる「八の字」に見えた。さらに下の小さい光が涙目に見えた。玉の向きは面の横向きの 3 割だけ(`EYE_YAW` 0.3)にしてほぼ正面へ、光は 1 つを目の上の真ん中(`CATCH_MIRROR`、u = 0)。内寄り(u 0.16)は、目の上の内の端が平らに見えて少しにらむ顔になった。外寄り(u −0.14)も下見では穏やか。横の広げが 1.12 → 1.02 に減る分、目の横の半径を 1.6 → 1.72 倍にした。
- **斜めの顔で向こうの目が頭のふちから出る**: 玉の前の出っぱりが 10〜11 mm あり、35° で輪郭の外へ黒く出た。埋めを深く(`EYE_CLEAR` −12〜−16 mm)すると目の上がおでこに切られて怒り顔になり、薄く・上へ傾けても輪の決め方で前へ出て効かなかった。**効いたのは、目の点ごとに「頭の面から 6 mm 前」を上限にして戻すこと**(`EYE_MAX_OUT`。4 mm では会話の高さから見て目の上の端が平らになった)。面との交わりの線は変わらないので、正面の目の形はそのまま。光は目の面より 0.8 mm 前のまま。
- **光が浮く(おじぎ)**: 光の真ん中と上の端が頭の面より 1.5 mm 以上前にあるかを確かめて置く(足りなければ目の真ん中へ下げる、`CATCH_MIN_CLEAR`)。光は目の物に合わせてあり、目の骨と一緒に動く。
- **笑顔の目(シェイプキー `eye_smile`)**: シェイプキーは足し算なので、下まぶたを上げる「縦に寄せる形」は、`eye_blink`(縦に 0.08 へ寄せる)と同時に効くと上下が裏返る(裏返らない条件は 0.08 − w(1 − k) > 0 で、ほとんど寄せられない)。代わりに **弧(真ん中が上がる ∩)より下の目を奥へ 25 mm 押して頭の面の後ろに隠し、上を前へ 6 mm 出す**。光は真ん中へ縮めて奥へ。まばたきと重なっても上の細い線が残るだけ。アプリは character.json の `morphs` のキー名を、名前で全部のメッシュに入れる(`creator/viewer/rigRuntime.js` の `_apply`)ので、`"happy": {"mouth_wide": 0.9, "eye_smile": 0.9}` と書くだけで効く。押すだけ(前へ出さない)だと、目の上の端が面に埋まっているので細い切れ端しか残らなかった。
- **背中の筋が「黒い裂け目」**: `wrap_band` の taper 0.16・taper_min 0.45 で、長さのほとんどが同じ幅の長い丸い帯(幅 0.068)。芯は太さをそろえて端だけ丸く(半幅 0.40 ×(1 − |2s − 1|⁴)^0.5)、色はほぼ黒 (41,40,38) からこげ茶 (52,41,40) へ。
- **手をふる**: 前の形は `arm_amp` 0.45 が掛かって 58° しか上がらず、もう片手はおなかのまま。`b04_motions` に `spec["motion"]["wave"] = {"style": "high", ...}`(arm_amp を掛けない。無いキャラは前のまま)を足した。**大きな頭と丸い肩では、腕を 100° より上げると肩の付け根がほおの下に入った**(BVHTree.overlap で 100〜250 の三角形)。肩を外へ 10 cm・後ろへ 2 cm・下へ 2 cm ずらし(骨の loc)、腕を後ろへ 15° 倒し、頭を反対へ 10° かしげると、外へ 145° ± 16°・1.7 回/秒でめり込み 0、手の上の端は高さ 0.76 m(目の高さ 0.81 m の少し下。前へ倒す fwd を足すと、世界の軸の回し順で手が下がった: 0.55〜0.59 m)。かしげを 12° より大きくすると、反対の肩が頭に入った。左手は外へ 16° でおなかから離す。
- **頭と胴の段・あごの下のすき間**: 頭を胴へ 8 mm 沈める(`NORRIE_HEAD_SINK`。耳の先の高さは保つので、胴の縦が 0.924 → 0.9375 になる)。動き 5 つのめり込みは 0 のまま。
- **流し方**: 案を 4〜6 個、環境変数で builder → b07 → めり込みの数えまで並べると 1 回 10 秒(CPU の札、`--procs 6`)。顔と笑顔・まばたき・後ろは Cycles の CPU の下見(`prev_extra.py` でシェイプキーを入れて撮る)で決め、GPU の札は最後の確かめだけ(組み立て → 取り付け → 写真 → 表情 → 頭のすき間 → check_all → 姿勢 → 試験 で約 3 分)。
- **頭のすき間**(`work\S5\tools\head_gap_check.mjs --set quick`): 手をふる・おじぎ・話す間は合格。幅 390 で 7 歩の札を開いた時だけ 5.8%(決まり 6%、1.6 px 足りない)。手をふるの頭のかしげで動きの出っぱり(motionRise)は 0.032。
- **確かめていない**: おじぎで耳の付け根と頭の横に出る細い線(殻の重なり。全部の案に出る)は直していない。

## 案 C の 2 回目の直し(NC3、2026-11-07 夜、`creator/builders/norrie.py`)
判定役の「にらむ目・2D と別の表情・背中の芯の階段と首の折れ・袖の多角形」と、本人の「斜めの顔がだいぶえぐれてる」を直した。
- **にらむ目の正体**: 頭に埋めた玉は、見える輪郭が頭の面との交わりの線になる。顔の面が斜め・くさび形だと、上が平らで外の角がくさび形になり、正面・おじぎ・斜めで「にらむ目」に見えた(深さや上限 6 mm の戻しでは直らない)。**目を「面に沿う薄いレンズ」にする**(`NORRIE_EYE_LENS`): 軸 = 頭の面の向き(上下も)85% + 正面 15%、赤道の輪を面より 0.6 mm 前、前のふくらみ 3 mm。正面から丸く見えるよう、横は 1/cos(横の向き)、縦は 1/cos(上下の向き)だけ広げる。おじぎ・斜め・手をふるでも丸い(向きで縮むだけ)。
- **レンズの後ろ半分は 4 倍深くして頭に埋める**(`NORRIE_EYE_BACK_K`)。前後同じ厚みでは、検査 ③ が目を「体に触れていない(浮き)」で落とした(埋まり 0.003 → 0.18 で合格)。赤道の輪は動かないので、正面の形は同じ。
- **まばたきの縦寄せは、寄せた先の頭の面に奥行きを合わせ直す**(面からの前の量を保つ)。面に沿う目は、寄せるだけだと下の縁が前へ浮く。
- 光は 2D と同じ大小 2 つ(見る人の左上に大 0.30・右下に小 0.13、両目で同じ向き、`NORRIE_CATCH2`)。丸い目では涙目に見えなかった(自分の目で見ただけ)。
- **斜めの顔のえぐれ**: `FACE_SHAPE` の前半分の指数 p 1.16〜1.2(くさび)が、大きな頭では斜めから「ほおがえぐれた」に見えた。p を丸い断面(約 2)へ、d(広い所を後ろへずらす量)も一緒に寄せる(`NORRIE_FACE_MIX`、既定 0.5)。全部丸く(1.0)すると、横から見えるクリームの顔が絵の 87% → 53% に減り、横から目もほぼ見えない。0.5 で 66%、0.7 で 60%。正面・横・後ろの輪郭の重なりは変わらない(前の端・後ろの端・最大の幅が同じ)。測り方: m02 の横の絵で、顔の行(py 200〜470)・前の側のクリームの画素を数える(`work\N_cute\C3\work\side_match.py`)。
- **背中の芯の階段**: 面の材質を列ごとに切り替えると縁が階段になる。芯の列は真ん中 9 列に固定し、断面ごとに列の点を元の断面の折れ線の上で動かして、芯の縁を ±half(高さ)の曲線に乗せると、なめらか(帯の面から離れない)。芯の外では列を幅 0.05% まで寄せる(0.4% では寄りで細い線が見えた)。絵の芯は帯のほぼ全長なので、芯の上の端を 0.756 → 0.850 m に上げた。
- **首で帯がカクッと折れる**: 帯を高さで頭と胴の骨に分けると、頭が向きを変えた時に首で折れた。首の上下 3.5 cm で重みを混ぜる(b07 は頂点グループの重みをそのまま使う。めり込み 0 のまま)。
- **袖の付け根の多角形**: 腕を高く上げて肩を外へ出すと、管の平らな付け根の端が体の外に出た。付け根に同じ半径の、腕の向きに平たい楕円体を足して丸める。深さ 1.0(球)・0.8・0.6 は、下ろした腕やもう片手であごに入った(めり込み 14〜66 三角形)。0.35 で 0(`NORRIE_DOME_DEPTH`)。
- 流し方: 案を環境変数で 2 つずつ CPU で組んで、めり込みの数え・Cycles の下見・横の m02 を 10〜20 秒で見て、GPU の札は最後の 1 本(組み立て → 写真 → 表情 → 頭のすき間 → check_all → 姿勢 → 試験、約 3 分)。
