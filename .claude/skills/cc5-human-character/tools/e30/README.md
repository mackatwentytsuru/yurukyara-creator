# e30: 写真(手本)と CC5 の頭を、計算だけで比べて合わせる道具(2026-11-03 作成)

AI の文章の判断は使いません(顔の形の小さな差を判定 AI は拾えなかったため)。手本の絵は、顔の写真から画像生成で作った物で、このフォルダには入れていません。

- `et_face.py`: MediaPipe の顔の点で、部位別(目・眉・鼻・口・輪郭・全体)の差(%IOD)。顔の点のモデル `face_landmarker.task` は入れていません(MediaPipe の公式の配布物を `models\` に置く)。
- `e30_metrics.py`・`e30_metrics_validate.py`: 顔の点・SSIM・HOG・輪郭の面を、答えの分かる組で確かめる。
- `e30_eye_direct.py`・`e30_card_eyes.py`: 目の見え方を画像から直接測り(黒目の径・明るさ・色相・まつげ・目頭の赤さ)、手本と CG を同じ倍率で並べた「目のカード」を作る。
- `e30_score_dirs.py`・`e30_loop.py`: 自動の最適化(各モーフを ±δ 動かして撮り、1 つずつのニュートン法の一歩を足し合わせ、悪化したら歩幅を半分に)。CC5 のブリッジ(`et_cc5.py`)で撮る。
- 測りの使い方・落とし穴は、スキル本文の「自動写真判定」の節。
