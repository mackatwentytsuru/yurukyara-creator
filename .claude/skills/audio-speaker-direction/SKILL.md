# 声の向き + 映像で「誰が話しているか」

## 作り(すべて期間中に新しく書いた。期間前の道具のコードは使っていない)
- `web/src/tracking/audio/stereoBearing.js`: 左右の音 1 枠(2,048 サンプル)から、時間差(GCC-PHAT。相互相関を 4 倍に補間して 1/4 サンプルで読む)と音量差を出す。`StereoBearingTracker` が枠に切って、揺れ(σ)と確かさつきの測定値を返す。純粋なロジック(node --test で確かめる)。
- `web/src/tracking/speakerFusion.js`: 各人の「話している」確率を、映像(口の動き)と音(向き)の証拠の掛け算で出す。片方だけでも動く。映っていない人の声は「映っていない誰か」の仮説で受け、向きだけ返す(`unseenBearingDeg`)。`AttentionPicker` が `ctx.audio` を受けて使う(`speaker: {id, confidence, source}`)。
- `web/src/tracking/audio/stereoMic.js` + `web/public/stereo-tap.worklet.js`: ブラウザのマイクから左右を**時間ずれなく**取り出す(AudioWorklet)。2 チャンネルが取れなければ「モノ」と伝えて止まらない。
- 画面: 「声の向き」の札(右 12°・確かさ・話し手が音/映像/音+映像)。URL: `?micspacing=<m>`(マイク間隔。既定 0.06)・`?mic=<名前の一部>`・`?micswap=1`・`?ild=<度/dB>`。

## 決まり
- 必要な機材は「カメラ(スマホ/ウェブカメラ)+ステレオのマイク」だけ。どちらか片方でも動く。
- 向き: マイクの正面 0・マイクから見て右が正。キャラの座標(+x が お客さんから見て右)からは `bearingOf` で直す(マイクは +z を向く)。マイクの位置・向きは `AttentionPicker` の `mic`。
- 音は端末の中で数字にするだけ。保存・送信しない(`test/privacy.test.mjs` が、通信・保存・録音の道具が無いことを確かめる)。キャラ自身が話している間は、自分の声を拾うので使わない(`main.js`)。

## 分かったこと(2026-11-03)
- **確かさは「位相の揃い具合(coherence)」で測る**。相互相関の山のめだち(PSR)は、雑音との差がほとんど出なかった(声 2.4〜2.7・雑音だけ 1.5〜1.8)。揃い具合は、声ありと雑音だけで差が出た(雑音だけの上位 10% が 0.15〜0.34)。間隔が広いほど床が上がるので、床 = 0.15 + 0.5×間隔(m)。
- **時間差を測る帯域の上は c/(2d)**(間隔が広いと空間のエイリアスで崩れる)。下は 300Hz。
- **エコー消し・雑音抑制・自動音量は切る**(切らないと、ステレオが 1 つにまとめられたり、左右の差がつぶれる)。2 つ目の `getUserMedia`(聞き取り用とは別)で取る。
- **2 つの AnalyserNode では左右の時刻がずれる恐れがある**(128 サンプル = 約 3ms で、時間差の読みが壊れる)。AudioWorklet で 1 つの処理の中から左右を同時に渡す。
- 間隔の設定が実際と違うと向きは大きく外れる(設定が半分だと、30 度が別の角度に)。**間隔は機材ごとに実測する**: `web/scripts/audio-calibrate.mjs`(既知の角度で鳴らして、実効の間隔と音量差の係数を最小二乗で出す)。
- 間隔が極端に短い・向きのあるマイクの組(X-Y など)は、時間差がほとんど出ない。その場合は音量差(ILD)が主になる。`ildDegPerDb` を実測で入れる(既定は 0 = 使わない)。

## 試験と数字(計算で作った声。実機のマイクではない。`web/scripts/audio-eval.mjs`、結果は `docs/audio_eval/`)
- 向きの誤差(6cm、雑音 25dB): 枠ごとの中央値 1.0°、90% で 4.0°。10dB で 3.9°/15.4°。0dB で 7.4°/20°(確かな枠 66%)。3cm は倍ほど粗い。
- 話し手の見分け(音だけ、2 人): 角度差 10° 以上で 16/16(雑音 20dB)、5° は決めない回が多い(間違えるより決めない)。同時に話す(相手は半分の音量)と、10° で 13/16、5° は決めない。
- ブラウザの経路(`audio-e2e.mjs`、偽のステレオ録音を偽のマイクに): −60°・−30°・0°・30°・60° が、−60.1°・−30.2°・−0.1°・30.3°・60.3°(±0.6〜1.2°。`docs/audio_eval/ブラウザの経路.json`)。
- 測っていない: 実機(録音機)の精度・店の騒がしさ(人の声・音楽・反響)・複数の人が実際に話す場面。実機は、角度のわかる音源が要る(`audio-calibrate.mjs`)。

## 録音機(2026-11-03 の確認)
- 作業用 PC の OS から、USB 複合機器「録音機」として見える: オーディオ入力「マイク (Audio Control (DVR))」(2ch・16bit・44.1/32/22.05/11kHz)と、USB 大容量記憶(M:\)の両方。USB マイクとして 2 チャンネルで録音できた。
- 7 秒ぶんの声らしい音を PC のスピーカーから鳴らして録った(録音は消した)。左右の音量はほぼ同じ(差 1〜2dB)。スピーカーの向きが分からず、信号が弱かった(−45dBFS ほど)ので、時間差からマイク間隔は出せなかった。**間隔・精度は未測定**。
