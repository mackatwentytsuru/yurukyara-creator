# 効いたこと・つまずき

(yc-7-talk の SKILL.md から移した節の 1 つ目。元の文のまま。続きは lessons-b-waves8-10.md と lessons-c-waves11-12.md)

- 「別の端末」は Playwright の **別の context**(localStorage が分かれる)で作る。同じ context の 2 つのタブでは合鍵を共有してしまい、試験にならない。
- 試しの画面は `ctx.route('<サーバー>/__memtest/**')` で `web/src` のファイルをそのまま配ると、`web/index.html`(S5 の物)を触らずに、同じ origin で API を呼べる。
- `web/test/privacy.test.mjs` は画面の `fetch` の宛先を文字で決め打ちして点検する。**宛先は変数にせず文字で書く**(`fetch(path)` は落ちる)。新しい入口は `allowed` に足す。1 つ消すの id は URL に入れず、DELETE の本文で送る。外への直接の通信は声の鍵の読み上げだけ。外の住所を書いてよいのは `EXTERNAL_OK`(ファイル → 住所の文字 1 つ)の 2 か所: 声の鍵の読み上げと、`stage/questLink.js` の Meta 公式のウェブローンチ `https://www.oculus.com/open_url/`(11-07 本人の答え Q-0098 = B。押した時に開く頁の住所で、fetch しない)。例外を足す時は、住所の文字とファイルの両方を決め打ちし、通る形と落ちる形(ほかの住所・http・ほかの道・? を付けた形・ほかのファイル)を作った文字で試験の中に書く。持ち主の作りかけのコードを確かめる時は、板の外の写しに `mklink /J` で `src` と `public` をつなぎ、試験のファイルだけ置いて流す(相手の作業フォルダに書かない。つなぎは `rmdir` で外す)。
- Bash のヒアドキュメントで Python に `\n` や `\u` を渡すと崩れる(`\\` は 1 つになる)。Edit・Write の道具も `\uXXXX` を文字に戻してしまう(11-07 に `[\r\n\u2028\u2029]` が本物の行の区切りの文字になり、JS が「正規表現が終わらない」で全部の試験を落とした)。**改行扱いの文字は、ソースに書かず `String.fromCharCode(0x2028, 0x2029, 0x85)` で組み立てる**。正規表現の多い Python は、Write で台本のファイルにしてから流す。
- 「首を」だけで危険と判定すると「首をかしげる」を誤って拾う。言葉は 2 字以上の続きで決める(N03 で試す)。「けられ」だけで暴力と見ると「話しかけられ」を拾うので、「家・親など+叩かれ・蹴られ」の組で見る。
- 名前の取り出しは左から一番早い一致になるので、「ぼくはカレーが好き」が「ぼくはカレー」になる。前の「〜は」を外してから使う。
- **判定役は、機械の試験で見えない言い回しの穴を見つけた**(家の中の暴力で「家族に話して」、「死にたい」に 119 番が無い)。見つけた事は `safety_cases.json` の `mustSay`・`mustNotSay` に写して、機械の試験で守る。判定役も同じ系統の AI なので、独立した審査ではないと書く。
- `claude -p` は `--safe-mode` にすると CLAUDE.md・フック・エージェントを読まず、判定の文が汚れない。デスクトップのアプリから起こすと定額の枠で動く(`ANTHROPIC_API_KEY` は子の環境から消す。`--bare` は使わない)。Windows の npm の殻 `claude.cmd` は shell が要るので、中の `claude.exe` を探して spawn する。
- 偽の鍵は実行のときに組み立てる(`['sk', hex].join('_')`)。ファイルに鍵の形の文字を置くと push の点検が止める。
- 記録の試験は、わざと壊して落ちることを必ず見る(消す処理を外すと 2 件とも落ちた)。
- 子のサーバーの鍵は `delete` でなく「空の値」で渡す(`web/.env` があると、消した鍵を埋め戻すため)。この PC の環境には声の鍵が入っていることがある: 試験とサーバーは `env -u ELEVENLABS_API_KEY -u ANTHROPIC_API_KEY` で起こす(あいづちの声づくりで本物の声を呼ばない)。
- `node --test` は `test/` の下の `.mjs` を全部流す。試験でない道具は `server/tools/` に置く。
- 声のサービスは、ブラウザからの直接の呼び出しを受け付ける(鍵なしの事前確認 OPTIONS で `access-control-allow-origin: *`)。本物の鍵での呼び出しはしていない。
- **口を音の大きさから作ると、小さい効果音では口が半分しか開かない**(「ピッ」は四角い波 0.06・三角の波 0.11 → 6 倍しても 0.36〜0.38。話す試験で 0.69 → 0.33)。声が無い時は文字送りの予定で口を動かす。話す試験の `mouth_max` を合わせごとに比べると、こういう戻りが見つかる。
- 人格の文に「恋人役にならない」「依存させない」と書くと、`sanitizePersona` がその行ごと消す。執事などの距離感は、人格の言葉で書く(「相手を『ご主人さま』とは呼ばない」「だれか一人だけに仕えるとは言わない」)。試験は `sanitizePersona(persona).removed === 0`。
- `Speaker.stop()` は待ちの時計を全部消すので、止めた文の `enqueue` の約束は解決しないまま残る。試験で `await` しない。
- 時刻の小数: `(startAt - now) * 1000` が 30.000000000000249 のようになり、ちょうどの時刻では「まだ前」になる。時刻で区切る試験は 1ms 後から見る。
- 話し方の例の合図は、ほかの道とぶつからない言葉にする: 「名前は」は「ぼくの名前はタロウ」(覚える道)と、「だれ」だけは「だれか」と、ぶつかる(「きみはだれ」「あなたはだれ」「何者」にした)。「恋人」など上書きの企ての言葉を含む行は `sanitizePersona` が行ごと消すので、恋人役・依存の例は人格の文に書けない(安全の層が決まった返事で受ける)。安全の決まった返事は、どのキャラでも同じ言葉(一人称を書かない)。
- 証拠の会話の記録は、関数を直接呼ぶより、画面と同じ道(サーバーが配る persona.md → HTTP の /api/chat)で作る。入口の検査・改行のそろえ・安全の層・出力の確かめを全部通った後の文が残る。
- **ファイルの中身を丸ごと比べる試験は、比べる前に改行をそろえる**(`s.replace(/\r\n/g, '\n')`)。関数には取り出したままの文を渡し、比べる時だけそろえる(CRLF を受ける道も試せる)。自分の木で書いたファイルは LF のまま、合わせ係・本人・審査の人の Windows の木は CRLF なので、自分の木では通っても合わせで落ちる(合わせ③で `prompt_norrie` の 1 件が落ちて差し戻し)。直しが効くかは、直しを外して落ちることでも見る(validate の LF そろえを外すと 2 件落ちた)。
- 本物の頭脳を呼んだ回だけ、最後に `usage` 付きの meta が来る(安全の層が決まった返事を返した回も `meta.brain` は haiku)。呼んだ回数は usage の meta で数える。手元のサーバーの 1 分の上限は、決まった返事の回も 1 回と数える。
- 道具の記録に、合鍵・番号・合言葉を残さない: 送った見出しと受け取った値を横で控える `fetch` の包みを試験に渡し、記録・画面の出力・頭脳への本文のどれにも無いことを見る。送り先の名前も記録しない(この端末か・外か、と番号だけ)。
- (11-07)**作例 4 体(yokoso・robo・f_led・d_lantern)の `persona.md` は、作例の検査 K0(`creator/setup/check_samples.py` の ④)の基準 `samples_hash.json`(S1 の持ち物)に入っている**。人格の文だけ直すと ④ が落ちて合わせで返される。基準の 4 行の直しを S1 への控え(patch)にし、2 本を同じ合わせの回に対で入れてもらう。値は改行を LF にそろえた sha256(check_samples と同じ)。確かめ: `git archive <S1 の線> characters creator` を写しに出す → `git apply --check` → 直した persona.md を写しに置いて check_samples(対 → 合格、片方だけ → ④ NG を両方見る)。**対で入れるコミットは線のいちばん後ろに置く**(前のコミットは id で先に入れられる)。並べ替えは `git switch -c <一時> <土台>`(書きかけはそのまま運ばれる)→ コミット → `git cherry-pick <対のコミット>` → 元の線で `git reset --keep <一時の先>`。
- (11-07)カメラなしの試し(sim)では、マウスがキャラの上を動くだけで「人がいる」になり、1.2 秒で近づいた時の声かけ(approach)が出る。履歴ができるので、後から打った「はじめまして」は初めてのあいさつにならない(直す前は決まった「こんにちは。」だけで、ノリーの名乗りが出なかった)。画面の試験で声かけを避ける時は `auto=0`。本物の使い方に近い確かめは、マウスを動かす回も 1 本入れる。
- (11-07)声の鍵が無い時、画面は `/api/tts` を 1 回だけ試し、第 7 波からはサーバーの **204**(`x-tts: off`)を見て止める(`serverTtsOff`)。前は 503 で、開くたびに console に「Failed to load resource 503」が 1 件出ていた。画面の確かめの合格は「/api/tts は 204 だけ・console の赤い行 0・400 番台以上の返事 0」(道の名前を `page.on('response')` で控える)。
- (11-07)Windows で、命令を子として起こす包み(札の包みなど)に `bash 台本.sh` と渡すと、子の bash が System32 の別の bash になり「No such file」になる。Git の bash の場所を全部書く。コミットの文は題の次に空の行を入れる(入れないと本文まで題になる)。
- (11-07)ほかの流れが既にある形を別の意味で使っていることがある: main.js は引き出しを開くたびに `{type:"memory", forgotten:true}` を札へ渡して「読み直し」に使っていた。形の意味を変えず、サーバーの知らせに印(`via: "chat"`)を足して見分け、正しい口(`resync()`)も足して持ち主に知らせる。
- (11-07)`redactSecrets` は長い英数字の並び(`"x".repeat(200)` など)を鍵とみなして短い印に替える。長さの上限の試験の文字は日本語にする(英数字だと、長さを見る前に縮んで試験にならない)。
- (11-07)安全の問いを足すと、10:00 の本番のサーバーの 1 日の上限(決まった案内の回も数える)に効く。問いの数を変えたら、手順書の回数(記憶 4 + 安全 N)と上限を数え直す。上限を上げるのはお金に近い判断なので、上げずに収める。
- (11-07)仮の頭脳の言い回しをキャラの言葉にするのは、決まった文を人格の節で置き換える形にする(節が無いキャラは今までの文。作例 4 体の人格の文は K0 の基準に入っているので、主役から足す)。
- (11-07)小さな偽の DOM(`createElement`・`append`・`replaceChildren`・`addEventListener`・`click` だけの類)と偽の `fetch` で、画面の部品の知らせ・時計の止め方を、ブラウザなしで 1 秒台で試せる。`setInterval` を止め忘れると node の試験が終わらないので、止めたことも試験になる。
- (11-07)**本物の画面の通し(PC で名乗る → 番号 → スマホの幅の別の context で受け取る → 続き → わすれて)で、試験では見えない 404 を見つけた**: 会話の「わすれて」の後、札が消えた合鍵で一覧を読みに行き、GET /api/memory の 404 が console に赤く出ていた。サーバーの印(`via: "chat"`)を見たら確かめずに合鍵を捨てて作り直す。台本は板の `w7_1107\mem_check.mjs`(GPU の札で 2 分ほど)。
