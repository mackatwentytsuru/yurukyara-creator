- (11-07 第 11f 波)**前の回の作りかけから続ける時**: 札(状態の板)が「未コミット: なし」でも、木に作りかけ(変更・新しいファイル)が残っていることがある。最初に `git status --short` と `git diff HEAD` と新しいファイルを全部読み、試験を流してから続きを決める(この波は、作りかけの 4 本がそのまま全部通った)。
- (11-07 第 11f 波)**番号の時計を出す DOM の試験は、`t.after` で「全部わすれる」を押す**: 途中の確かめで落ちると、10 分の `setInterval` が残って node の試験が 10 分終わらない(わざと壊す確かめで、道具の時間切れまで止まった)。`t.after(() => parent.find('mem-forget').click())` で、落ちても 1 秒で終わる。わざと壊す確かめは、DOM を使わない試験のファイルだけで先に流すと速い。
- (11-07 第 11f 波)**`<dialog>` の後ろを暗くするのに `::backdrop` は使えない**(style の属性では塗れない。style.css は画面の流れの持ち物)。dialog を `width/height/maxWidth/maxHeight: 100%`・`margin: 0`・半透明の地にして、中の wrap(`display: grid; placeItems: center; minHeight: 100%`)に箱を置く。**dialog の `display` は替えない**(替えると、閉じた時に隠れる決まり `dialog:not([open])` が効かなくなる)。
- (11-07 第 11f 波)**ブラウザの確かめで `/#pair=…` を開く時**: 今 `/` を開いているタブで `/#pair=…` へ移ると、同じ頁の中の移動になり、頁を読み直さない(窓が出ない)。一度ほかの URL(`/api/status`)へ移ってから開くか、新しいタブで開く。

- (11-07 第 12a 波)**場所の指定(?place=)が無い時、画面が送る「試しの場所」(src/place.js の SAMPLE_PLACE。受付とスタッフの部屋の目印つき)が毎回指示文に入り、ノリーが「スタッフさんに聞いてみて」と言った**(本人の VR の試し V1)。サーバーの指示文(prompt.mjs の `hasPlaceInfo`)は、名前が「試しの場所」の物と、目印も説明も無い物を「場所なし」と数え、場所の節・引き継ぎの案内・`landmark:` の案内を出さず、「分からない時は、分からないと正直に言う(handoff は使わない)」にする。試験は、ノリー + 場所なしの指示文の**全体**に「スタッフ・受付・ご用」が 0 件(今までの試験は persona.md しか見ていなかった)。画面側の試しの場所そのものを空にするのは place.js の持ち主(S5)の仕事なので、サーバーは名前で外して守る(`TRIAL_PLACE_NAME` と SAMPLE_PLACE.name が同じことも試験が見る)。
- (11-07 第 12a 波)動きの説明は、そのキャラが持つ動きだけを `describeMotions` で説明し、例(`pickMotion`)も持つ動きから選ぶ(ノリーは bow・nod・wave だけで、tilt・point・shake は無いのに、例が tilt を教えて返事 54 文中 8 回が tilt だった)。ない動きを頼まれたら「まだできない」と言わせる。試験は、指示文の中の `"motion":"…"` を全部拾って、持つ動きの中かを見る。
- (11-07 第 12a 波)**聞き違い(「ノリー」→「乗り」「おのり」)は、聞き取りへ名前を手がかりに渡して減らす**: 画面は見出し `x-stt-hint`(URL エンコード)、サーバーは係へ「パス<タブ>名前」の 1 行で渡し、`stt_worker.py` が `initial_prompt` と `hotwords` にする(faster-whisper 1.2.1 で両方ある。無い版は initial_prompt だけに戻る)。手がかりは文字・数字・「ー」だけ 40 字(係の入口は 1 行 = 1 件なので、改行・タブを入れさせない)。名前だけを返した時は空にする(無音で手がかりを言い返す癖の対策)。手がかりは会話(`Dialogue`)が、作った時と送るたびに `sttHint.js` へ入れる。**main.js が `new Listener(..., { hint: () => 名前 })` と渡せば、最初の声から効く**(今は会話ができた時点から)。実際の聞き違いが減ったかは、本物の声で数える(まだ測っていない)。
- (11-07 第 12a 波)**返事が 1 文も来ないまま止めた回の言葉は、`cancel()` の中で控える**(`this.carry`)。止めた後の `send` の await が戻るのを待つと、新しい `send` が先に控えを読んでしまう(割り込みの `send` は、前の回の `cancel` を同期で呼んでから進む)。つなげる条件: 返事が 0 文・近づいた合図でない・30 秒以内。近づいた合図の回は控えを消費しない。履歴には、つないだ形で残す。
- (11-07 第 12a 波)**問いの形(「ノリーが好きなものを教えて」)から「好きなもの: ノリー」を覚えていた**: 好き の前の「が」が、聞かれた側の名前に当たる。文ごとに分けて、`?`・教えて・何が・どんな・〜か の文は読まず、「好きな + もの・こと」の形(好きな物を指す言い方)と、キャラ自身の名前(人格の見出し `# 名前`)は覚えない。つまずき: `いつ` を問いの言葉にすると「いつもカレーが好き」まで落ちる(`いつ(?!も)`)。`ー` は `\p{Script=Katakana}` に入らない(Common)ので、`CALL_RE` は「ノリーって呼んで」に最初から当たらない。
- (11-07 第 12a 波)**履歴の安全の注意**: 履歴の返事は画面(=使う人)が送る物なので、「返事があるから答えてある」を信じる 1 回だけの扱いは、恋人・依存だけにする。つらい話・命の言葉は、返事があっても数える(作り物の返事 1 つで外れていた。CRITsec3 L1)。

- (11-07 第 12a 波)privacy の見張りは、文字の見かけを変えた住所もほどいてから探す: `\/`・`\uXXXX`・`\u{…}`・`\xXX`・`'ht' + 'tps://'`・`'//名前'`(この頁と同じ https で外へ行く)。index.html と CSS も読み、例外は help のリンク(GitHub の README)の 1 つだけ。通る例(正規表現の `//`・割り算・道だけの文字)も試験に入れて、見張りが広すぎて本物の木を落とさないことを見る(本物の木は 0 件で通った)。
- (11-07 第 12a 波)iPhone の消音スイッチ: `navigator.audioSession.type = 'playback'`(iOS 17 から。Web Audio だけの音は、消音スイッチで消える)を `unlock()` で。無い端末・書くと落ちる端末でも止まらない。実機での確かめはまだ(偽の navigator での試験だけ)。
- (11-07 第 12a 波)作業の落とし穴: Windows の Git Bash で、日本語と引用符・バッククォートが混ざった python の heredoc は途中で壊れて**一部だけ適用される**ことがあった(同じ直しが 2 回入り、関数が重複して「宣言済み」で全部の試験が落ちた)。直しの台本は Write で `.py` にして実行し、適用後に `grep -c` で 1 個ずつかを数える。標準入力の無い `cat > file` は入力待ちで止まる。`python -I` は `PYTHON*` の環境変数を読まないので、日本語の出力は `sys.stdout.reconfigure(encoding='utf-8')` で。
