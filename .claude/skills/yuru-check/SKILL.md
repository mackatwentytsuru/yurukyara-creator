# yuru-check: ゆるキャラチェック(画像の入口の分かれ道)

最初の設計の決め。画像から作るときの最初の段。言葉から作るとき(yc-0-draw)は要らない。

| | |
|---|---|
| 入力 | 絵・写真 1 枚(PNG・JPG) |
| 出力 | `<出力>/yuru_check.json`: `class`(yuru・human・complex)・`next`(look・offer_yurufy・offer_other_picture)・`message`(使う人に見せる一言)・判定役の答え・画素の数字 |
| 命令 | `python creator/pipeline/c01_yuru_check.py <絵> <出力フォルダ>`(1 枚 約 40 秒。claude -p を 6 回) |
| 試験 | `python creator/check/run_testset.py <出力フォルダ>` → 6/6 で合格(終わりの番号 0) |

## 分け方と次の手
- **yuru**(ゆるキャラ・マスコット 1 体・顔が読める・背景ほぼ無し)→ `look`: そのまま ① 見る段へ。
- **human**(人の写真・写実寄りや似顔絵ふうの人の絵)→ `offer_yurufy`: すぐ断らない。「これはちょっとリアルな人の絵みたい。特徴を生かして、ゆるキャラにしてみる?(別の絵にもできるよ)」。はいなら、特徴(髪の色・形、服の色、目立つ物)を言葉にして yc-0-draw でゆるキャラを描く。**どんな写真でもきれいに 3D にできるとは言わない。**
- **complex**(景色・物が多い・細かい部品だらけ)→ `offer_other_picture`: 主役を 1 つ選んで描き直すか、別の絵にする。

## 決め方(なぜこうしたか)
1. 新しい文脈の Claude 2 つ(Haiku 5.5・Sonnet 5.5)に、各 3 回、A/B/C の 1 文字で聞く(`j01_judge.ask_claude` と同じ呼び方)。2 回以上同じなら、その判定役の答え。
2. 2 つが同じならそれに決める。割れたら画素の数字(背景の白さ・色の数・細かさ・肌の色の割合・小さな塊の数)で決める。数字も決められなければ complex にして、使う人に選んでもらう。
3. 2 つとも同じ系統の Claude なので独立した確かめではない。最後は使う人が選べる(「別の絵にする」は、どの分かれ道でも出す)。

## 試験の結果(2026-11-06、Claude が SVG で描いた 6 枚)
- 6/6。判定役は 6 枚とも 2 つが同じ答え。Haiku は人の顔の絵 2 枚で 3 回中 1 回「A(ゆるキャラ)」と答えた(多数決で B)。Sonnet は 18 回全部正解。
- 数字だけ(`--no-ai`)でも 6/6 だったが、しきい値はこの 6 枚と作例 2 体を見て決めたので、割れた時の決め手にだけ使う。
- 判定役 36 回の量は、定価に直すと 5.8 ドル(手元の MCP と設定を読んでいた時)。`j01_judge` に `--strict-mcp-config --setting-sources project` を付けて、1 回の量が約 1/6 になった。

## つまずきと直し方
- 判定役が見本の形(「答え: A」)を外し、理由を先に書いて同じ行の終わりに「答え: C」、または「A. ゆるキャラ…」だけで答えた(Haiku で 36 回中 4 回)。読み取りを「答え: X をどこでも拾う → A・B・C で始まる行」の順にした。`--reuse` で前の答えを読み直せる(聞き直さないので費用 0)。
- 試験の絵は、実在の人・既存のキャラを描かない(`creator/check/testset/gen_testset.py`)。写真の試験をするときは、権利のある写真だけを使う。

## 確かめていない事
- 本物の写真(カメラで撮った人・物)。手描きのスケッチ(線だけで塗りが無い絵)。人の顔の絵の「ゆるキャラにしてみる」の描き直しの質。
