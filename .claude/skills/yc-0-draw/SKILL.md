# yc-0-draw: 絵を描く段(言葉や絵 → SVG の元の絵)

7 段の手前の 0 段目。ここで出した `<id>_元の絵.png` を、① `yc-1-look` が読む。絵が最初からある人は、この段を飛ばして ① へ行ってよい(元の絵を描き直したいときだけ、この段を使う)。

| | |
|---|---|
| 入力 | 言葉(キャラの説明 1〜3 文)、または絵・写真・スケッチ・手書き 1 枚 |
| 出力 | `<id>_元の絵.svg`・`<id>_元の絵.png`(1254×1254・白背景・正面・全身)・`<id>_元の絵_noshadow.png`(影なし。測る用)・`<id>_設定.md`(名前・色・性格・部品の一覧) |
| 確かめ方 | `python creator/pipeline/d02_check_svg.py <svg> <png>` が「不可 0」。目で見て 3 回以上描き直した記録。判定役(`d04_judge_draw.py`)の答えをそのまま記録 |
| 次へ | `<id>_元の絵.png` を ① `yc-1-look` へ(測る式 `l01_measure.py` は絵 1 枚を入れて数秒で通る) |

使う道具(全部 `creator/pipeline/`、Claude が書いた物だけ):
- `d03_svgkit.py` … SVG を書く小さな部品集(体の塗り・縁の暗がり・ハイライト・床の影・目・ほお・口・部品の表)
- `d01_svg_to_png.py` … SVG → PNG(Chrome のヘッドレス。GPU を使わない 2D)。`--noshadow` で影なしも出す
- `d02_check_svg.py` … 測れる形かの点検(余白・左右・輪郭・`<image>` が無い・文字はパス、など)
- `d04_judge_draw.py` … 描いた絵を、新しい文脈の Claude 2 つ(Haiku 5.5・Sonnet 5.5)が 1 語で判定

画像生成 AI や、Claude 以外の AI は使わない(描くのも、調べるのも、判定も)。`<image>`(画像の取り込み)も使わない。

## 手順(1 体 15 分を目安。段ごとの時間を記録する)

### 1. 設定を言葉にする(2 分)
描く前に、キャラの設定を次の型で 1 つの文書(`<id>_設定.md`)に書く。**描いている途中で色や部品を足さない**(足したくなったら、今ある形をもっと良くできないか先に考える)。

- 名前と id(英小文字)、一言の性格、どこで誰を迎えるか(分からなければ「おうちで、家族と話す」。お店・駅・学校は、使う人がそう決めた時か、置く場所の設定(?place=)がある時だけ)
- 一言の設計: 「丸い・単純な形・顔が読める」に合う形か。**類型**(下の 4 つ)を 1 つ選ぶ
- 色は **4〜6 色**を、役割で名前をつけて先に決める(体の明・体の中・体の暗・顔の濃い色・差し色・足)。**体の色は白に近くしない**(白い雲・白いおばけは、輪郭が白背景から分からず点検で落ちる。空色・クリームなど、縁が白から離れる色にする)
- 部品の一覧(あとで作る 3D の部品の元になる): 体・頭・手・足・目・ほお・口・帽子や飾り

言葉から作るとき、足りない所(色・性格・形)は、聞き返さず自分で決めて設定に書く。使う人が後で直せるよう、決めた物を最後に伝える。

### 2. 絵から作るとき(写真・スケッチ・手書き)
- **権利を確かめる**: 使う人が権利を持つ絵か。有名なキャラは描かない。
- 絵を見て、類型・色(4〜6 色)・顔の特徴・部品を、上の設定の型に書き起こす。**絵をそのまま取り込まず、SVG の図形で描き直す**(`<image>` は不可)。写真の人の顔や人型の体は、この手順では質が出ない。先に伝える。
- 元の絵に近づけたいときは、色の画素を標本に取る(`python -c "from PIL import Image; print(Image.open('x.png').convert('RGB').getpixel((x, y)))"`)。

### 3. SVG を描く(`creator/draw/gen_<id>.py` を書いて流す。5 分)
SVG を直接書かず、**座標を数字で持つ Python(`creator/draw/gen_<id>.py`)で書く**。あとで部品の表と builder の辞書に写せる。見本は `creator/draw/gen_kumomaru.py`(型 C)と `gen_pokotake.py`(型 B)。

**部品は決まった名前の組に入れる(2026-11-06 から必須。契約 K1 の `looks.2d.parts`)。** `k.add(<SVG>, "<部品の名前>")` の 2 つ目に、次の名前のどれかを渡す。書き出すと `<g id="char">` の下に `<g id="body">` などが並ぶ。2D の道(S2)が目・口・眉をこの名前で差し替え、3D の段が部品の表を同じ名前で読む。名前の一覧の正本は `creator/pipeline/d03_svgkit.py` の `PARTS`。

| 名前 | 中身 | 要るか |
|---|---|---|
| `shadow` | 床の影(`soft_shadow`)。`--noshadow` で外れる | あるとよい |
| `back` | 体の後ろの飾り(しっぽ・羽根・マント) | |
| `foot_R`・`foot_L`・`arm_R`・`arm_L` | 足・手 | |
| `body` | 胴(頭と胴が 1 つの型 B・C は全部ここ)。体に落ちる影・つやも同じ組に | **要る** |
| `head` | 頭(型 A・D で胴と分かれているとき) | |
| `ear_R`・`ear_L` | 耳・角 | |
| `cheek_R`・`cheek_L`・`eye_R`・`eye_L`・`brow_R`・`brow_L`・`mouth` | 顔 | **目 2 つと口は要る** |
| `hat` | 帽子・傘・頭の葉っぱ・ふた | |
| `accessory` | 前の飾り(たすき・名札・リボン) | |

- **左右はキャラ自身の左右**: `eye_L` はキャラの左目 = 絵の右側(x が 627 より大きい)。3D の骨の `.L` と同じ向き。ループで描くときは `"foot_R" if fx < CX else "foot_L"`。
- 同じ部品を、間に別の部品をはさんで 2 回に分けて描くことはできない(`Kit.svg()` が止める)。描く順を部品ごとにまとめる。
- ほかの名前が要るとき(例: 手に持つ物)は、勝手に作らず `accessory` か `hat` に入れ、要る名前を契約表 K1 に書いて持ち主(S1)が足す。

流れ:

1. `k = Kit()`(`d03_svgkit.py`)。体を **形の和**(円・楕円・角丸・パスの重ね)で決める
2. 後ろの物(足・手)から描く。足元の影は `soft_shadow`(id="shadow" になり、`--noshadow` で外れる)
3. 体は `solid_body`(斜めの光 + 縁の暗がり)。**輪郭線は引かない**
4. 体に落ちる影(頭が胴に、傘が軸に)は `contact_shadow` の `clip` を体の形にして、中だけに描く(外へにじむと、輪郭が汚れる)
5. `highlight`(ぼかした白い楕円)を 2〜3 個。大きいつやと小さなつやを置く
6. 顔(最後)。`eye`・`cheek`・`smile`
7. `k.part(...)` で部品を登録し、`k.parts_md(...)` を設定の表に貼る
8. `k.svg(scale, anchor, to)` で、体の高さを紙の 0.6〜0.8 にそろえる(描いてから大きさだけ直せる。拡大で左右の余白が 63px を切らないか、d02 で見る)

文字を入れるときは、`<text>` を使わず、フォントの字の輪郭をパスにして埋め込む(`fontTools` の `SVGPathPen` + `TransformPen`、y を反転)。

### 4. PNG にして、点検して、目で見る(1 周 1 分)
```bash
python creator/draw/gen_<id>.py <出力>/<id>_元の絵.svg <出力>/<id>_部品.md
python creator/pipeline/d01_svg_to_png.py <出力>/<id>_元の絵.svg <出力>/<id>_元の絵.png --noshadow
python creator/pipeline/d02_check_svg.py <出力>/<id>_元の絵.svg <出力>/<id>_元の絵.png --json <出力>/<id>_lint.json
```
d02 が「不可」を出したら必ず直す(これが「svg_lint 0 件」。部品の名前の点検もここ)。「注意」は意図したものか確かめる。そのあと **PNG を開いて見る**。`<出力>` はリポジトリの外の作業フォルダ。できた物だけを `creator/samples/` へ写す。

### 5. 描き直す(3 回以上。毎回、PNG を開いて下の見どころを見る)
**見どころの一覧**:
1. 顔が一目で読めるか(目が大きく、口が目より小さく、ほおがある。目の白いつやが 2 つ)
2. 左右の釣り合い(d02 の「鏡に映した重なり」が 0.85 以上)
3. 手足・飾りが体に埋もれていないか。**手足は「丸い太い塊」にして、体の外へ出す**(細い・平たい・埋もれると、判定役も「3D にしにくい」と言った)
4. 傘・つば・耳など**平らな飾りには厚みをつける**(薄い縁は 3D で割れる。縁を 2 枚重ねて厚く見せた)
5. 重なり順(後ろ → 体 → 影 → 顔 → 前の飾り)。顔が飾りに隠れていないか(ぽこたけの 1 枚目は、傘が目を隠した)
6. 色が沈んでいないか、色が 4〜6 色か、体の縁が白から分かれるか
7. 足元の影が外へはみ出していないか、紙のどこにも切れ目がないか
8. 「ただの丸」で済ませていないか。形を少し歪ませ、つや・影を 1 つずつ置き、線は太めにそろえる

**足さずに磨く**: 出来が悪いとき、飾りや部品を足さない。丸み・目の位置・影の濃さを直す。

### 6. 判定する(作った自分はしない。2 分)
```bash
python creator/pipeline/d04_judge_draw.py <出力>/<id>_元の絵.png <作業>/judge
```
問いは 3 つ(「ゆるキャラらしいか」「顔が読めるか」「3D にしやすい形か」)。各判定役に 3 回、2 回以上「はい」でその判定役の「はい」。答えの `D:` の行(直す所)を読んで、妥当なら 1 回直す。**合格を狙って、判定だけを繰り返さない。** 結果は、通らなかったものもそのまま記録する。2 つとも同じ系統の Claude なので、通っても、使う人の目が最後に決める。

### 7. 次の段へ渡す
`<id>_元の絵.png` を ① `yc-1-look` へ。測る式(`l01_measure.py`)は絵 1 枚で動く。`_noshadow.png` は、輪郭を測る道具(`s03_compare`・`s05_gaps`・`check_all.sh`)の「元の絵」に使う(影を体と数えるため)。設定の部品表は、builder の辞書 `D` の元になる。

## キャラの類型と、下絵の骨格

紙は 1254×1254。**足元(床)の y は約 960 に置いて描き、`k.svg(scale, anchor=(627, 960), to=(627, 床の y))` で大きさと位置をそろえる**。以下の数字は、描く前の座標の目安(ぽこたけ・くもまるで通した値と、前に作った 4 体の経験から。測って決めた規格ではない。A と D は、この段の試しでは描いていない)。

### A. 頭でっかちの二足(ぬいぐるみ・動物・ゆるい人型)
- 頭: 楕円、幅 540・高さ 470(中心 (627, 400))。胴: 楕円、幅 340・高さ 380(中心 (627, 690))。頭の幅 : 胴の幅 = 1.6 : 1(2〜2.5 頭身)
- 手: 楕円 幅 130・高さ 100、胴の左右。足: 楕円 幅 150・高さ 90、胴の下の左右(後ろに描く)
- 顔は頭の下半分。耳・角は、頭の円の上に半円で
- 頭が胴に落とす影を、胴の形で切って描く

### B. 球や箱の胴(おにぎり・パン・缶・きのこ・箱)
- 胴: 大きな丸(または角丸の箱)、幅 450〜600。顔は胴の上 45% に。ぽこたけ(きのこ)は、軸=卵形の胴、傘=丸い屋根が頭
- 飾り(傘・帽子・ふた)は **胴より 1.5 倍張り出す**と、ゆるキャラの形になる。厚みをつける
- 足は小さな楕円(幅 150〜180)、手は丸い突起

### C. 足なし(雲・おばけ・しずく・ゼリー・ふわふわ)
- 体は 1 つの塊(重ねた円の和)。**底は平らに**して、小さな足の粒を 2 つ置く(床に立つ。足なしだと 3D で立たせにくい)
- 谷間(円の重なる所)に、体の中だけの柔らかい影を落とすと、もこもこに見える
- 体の色は **白でなく、空色など縁が白から離れる色**にする。縁を暗くする(`solid_body` の rim)

### D. ロボット(箱の頭・箱の胴・円筒の手足・アンテナ)
- 頭: 角丸の箱 幅 480・高さ 340・半径 80。胴: 角丸 幅 360・高さ 300。顔は頭の画面(暗い面に光る目と口。この型だけは、顔が暗い点でなく光る点)
- 手足は円筒(角丸の細長)+関節の丸。アンテナは細い棒 + 丸い先
- 直線が多いので、**角は必ず丸める**(半径 40 以上)。面ごとに斜めの光

### 顔の型(全類型で共通。ぽこたけ・くもまるで通した値)
- 目: 暗い楕円(幅は顔の幅の 0.10〜0.12。縦長に)。左右の間隔は顔の幅の 0.25〜0.30。白いつやを大(目の幅の 0.36)と小(0.17)の 2 つ
- 口: 目の間隔より小さく、目の下。笑い口は「中を暗く塗った弧」+ 舌の桃色の楕円。細い線の口は端を丸く(太さ 9px 前後)
- ほお: 目の外側の下に、ぼかした桃色の楕円(透明度 0.55〜0.8。青い体の上では、桃が灰紫に沈むので濃いめ)
- 顔は体の中心より下。**目をつぶさない**(傘・前髪・帽子が目にかからない)

## つまずきと直し方(2026-11-06、くもまる・ぽこたけで出た物)
- 白に近い体 → 輪郭が白から分からない(d02 が落とす)。**空色・クリームにして、縁を暗く**。
- 傘の形を「楕円の和」で作ると、下半分も丸くなり、顔にかかった。**屋根は平らな底のパス(上だけ丸い)+ ふちの楕円**。
- `userSpaceOnUse` のグラデーションは、場所を決めて作る。**同じ 1 つを左右の手に使うと、右の手が暗くなった**。左右で別に作る。
- 全体を `scale` で拡大すると、左右の余白が 63px を切る(1.22 倍で 49px)。d02 の「余白」が落とす。拡大は 1.05〜1.1 倍にして、はみ出す手は小さくする。
- 判定役が「手足が細い・小さい・埋もれる」「傘の縁が薄い」と指摘した(両方のキャラで)。**手足を丸く太く、体の外へ出し、縁は厚く**描き直して 1 回だけ通した(判定の数字は record に書いた)。
- `python` の文字列に `\n` を書く所は、書き換えの途中で本物の改行に変わって文法が壊れることがあった。`chr(10)` を使うと安全。
