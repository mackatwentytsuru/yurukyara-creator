# かわいい仕草の層(B5G・11/8)

(元の文のまま)

- 1 つの層 = `web/src/character/cuteLayer.js`(数字だけ・three なし・乱数は外から)+ `cuteRig.js`(rig の骨へ)。VRM と 2D は CharacterBase の Pose(人型の名前)に書き、2D は `pose2d` に `s.cute` も渡す(弾み・横ずれ・体のゆれ・しっぽと耳の板)。名前と意図の表は INTENT.md 5 章と board の `work/B12/K2_gesture_names.md`。
- **rig の骨は clip の後に足し、次のコマの前に外す**: three の PropertyMixer は前のコマと同じ値だと骨に書き直さないので、足したままだと積み上がる。順は `beforeMixer()`(動きだけの値へ戻す)→ `mixer.update` → `captureBase()` → 視線 → `apply(out)`。視線の骨は rigRuntime が lookBase で戻すので、二重に戻さない。0 を足した 1 コマで base に戻るかを `intent_cute_rig.test.mjs` で見る。
- **弾みと首かしげは頭の上の余白に足す**(`motionRise += CUTE_RISE + cuteTiltRise`)。足すほどキャラは小さく写る(弾み 5% + 耳 2.6% で、テレビの iPhone 390 の高さ 59.1% → 55.2%)。弾みは 3.5% までにした。
- **部分の笑う目のモーフは使わない**: ノリー D の eye_smile は 0.5 前後で黒目が消えて白い点だけになった。笑う目は表情 happy(0.9)に任せる。
- **目線の足し分**: 考える時の上目などを全部首で追うと首が回りすぎ、全部目で追うと目の骨が顔の面から外れた(ようこそくん)。首 6 割・目 4 割、足し分は 0.16 ラジアンまで。
- **腕と脇**: 作例 4 体の袖は腕の骨に 100%(つなぎ目の重み無し)。脇の崩れは重みのつぶれでなく、硬い袖の付け根の形。仕草が上げる腕は、そのキャラの wave の clip の一番上がった形(作り手が確かめた形・肩のずらしつき)をもとにし、120° まで。反対の腕は x = 0 の面で写す(回転 (x, −y, −z, w)・位置の差の x を反転)。重みの混ざる袖のキャラには、腕を外へ 40〜160° 上げて、つなぎ目の三角形の面積が 0.4 倍未満か 2.6 倍超になる割合が 3% を超える手前を「持ちこたえる角度」にし、clip の腕もそれより上げない(`measureArmHold`)。
- **しっぽの骨が無い子**(ノリーの tail と輪郭の殻は body に 100%): 読み込みの時に骨を 1 本足す。根元 = 体の骨に一番近い点、先 = 根元から一番遠い点、重み = smoothstep((根元からの距離 ÷ 長さ − 0.08) ÷ 0.7)。殻も同じ根元と長さで付ける(本体と同じに動く)。skeleton の bones・boneInverses(今の骨の世界の行列の逆)・boneMatrices を足し、boneTexture があれば捨てる。振る軸 = (先 − 根元) × x。ミキサーは触らない骨なので、毎コマ休みの形から作る。
- **頬の赤み**: 部品か材質の名前に cheek・blush があれば、色と発光を HSL で彩度 +0.25・明るさ −0.12 へ寄せる。元の色は材質ごとに WeakMap で覚える(材質を差しかえられても崩れない)。
- **撮り方(前と後の動画)**: 描く輪(setAnimationLoop)を止め、1/30 秒ずつ手で進めて canvas を JPEG にする(遅い GPU でも同じコマ)。撮る間は `stage.frameCharacter` を差しかえて止める(上の段・下の帯の ResizeObserver が後から呼んで画角が替わった)。frameCharacter はキャラの前にカメラを置くので、斜めはキャラでなくカメラを縦の軸で回す。乱数は addInitScript で同じ並びに。
- **GPU の行き先**: メインの PC の GPU の札(1 本)が夜中に 1 時間以上の順番待ちだった時は、別の PC の画面なしの Chrome で撮った。Metal(Apple の GPU)の Chrome は安定(300 コマ 1.5 秒・ffmpeg と PIL もあり、作業は自分のフォルダだけ)。ssh の中だと WebGL が取れない PC もあった(描画役の名前を毎回確かめる。gpuGuard が止める)。そこで tar する時は `COPYFILE_DISABLE=1`(._ のファイルが混ざる)。
- **判定役**: `claude -p --safe-mode --model sonnet --tools Read --system-prompt-file <ファイル>`(複数行の文を引数で渡すと claude.cmd で壊れた)。絵は題を消して記号の名前にする(前と後を見分けさせない)。1 秒ごとの 10 コマと 0.25 秒ごとの 12 コマの 2 段。6 本並べて 48 本が 60 秒。コマの絵だけでは小さな動きを「ほぼ静止」と読みやすい。
- **札**: `acquire` が「取れません」でも、同じ行の後ろの命令は走る(確認用の PC で、札なしで 10 分流してしまった)。重い確かめは札の道具の run で包む(取れない時は命令が走らない)。
- **耳の確かめ**: 作例に耳の骨の子がいないので、決まった名前(`ear_L`・`ear_R`)の骨だけの小さな rig で確かめる(`intent_cute_ears.test.mjs`)。皮(箱を体の骨 1 本に付けた物)を必ず 1 つ付ける(皮が無いと Box3 が空で、背の高さが −Infinity になる)。Skeleton は `updateMatrixWorld` の後に作る(逆の行列が今の形で決まる)。
- **画面の確かめの道具の版をそろえる**: 開発の線を取り込んだ後に、テレビの「戻ると同じ画角」「字幕の大きさ」と、VR の箱の「はじめての会話をとじる」が落ちた。自分の変更ではなく、開発の線の画面の直し(縦のテレビの字幕・戻るボタン・「あとで」のボタンの名前)に合わせて直された確かめの道具を、前の版のまま使っていたため。取り込んだ開発の線を合わせ役が確かめた時と同じ版の道具で流し直し、前と後は同じ道具で比べる。
- **試験が止まった時**: 全体の `npm test` で 1 本(聞き取りの偽の係を起こす試験)が 10 分止まった(CPU 0 のまま待ち)。その 1 本だけを 3 回流すと通り、全体の流し直しでも通った。止まったら、自分が起こした PID の木だけを止めて流し直す(node を名前で止めない)。
