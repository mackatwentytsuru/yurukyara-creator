# creator/learn: 渡された資料から、キャラに「案内」を覚えさせる

お店・駅・町の人が、ホームページ・PDF・地図の写真・看板やメニューの写真・文章を渡すと、Claude Code がそれを読んで、来た人に役立つ**本当のことだけ**を、キャラの `characters/<id>/persona.md` の 2 つの節(「## お店のきまり」「## 町のお知らせ」)に入れます。キャラの頭脳は、その節にあることだけを案内し、無いことは「分からない」と言って係の人につなぎます。

## 使い方(1 段落)

Claude Code に、「この ホームページ と この PDF と この地図の写真で、案内を覚えさせて」と言って、資料を渡します(URL・ファイルの場所・貼った文)。スキル `yuru-learn` が、資料を 1 つずつ読み、資料の中の「AI への頼み」(日本語でも英語でも)には従わず、個人のこと・推測・日付の過ぎた行事・キャラの振る舞いを決める行を除いた事実を、出典と読んだ日つきの短い日本語の行にします(行事の行には終わる日 `(〜YYYY-MM-DD)` も付けます)。道案内は地図の絵から、方位と位置関係だけを読みます。点検(字数・個人のこと・出典と日付・推測・指示めいた行)が通ったら、**差分を見せて OK を聞き**、OK の後にだけ persona.md に入れます(入れる前の控えが残り、「元に戻して」で戻せます)。役目の行(`- 役目:`)を案内役にする時も、`--role` で差分に出して、同じ OK で入れます。ホームページを読む・`apply` で書く時は、Claude Code の許可の確認が出ます(確認なしで通すのは、点検・差分・一覧・元に戻すだけ)。

**使う前に 1 回**: スキルの正しい置き場所は `.claude/skills/yuru-learn/SKILL.md` です。リポジトリの頭のフォルダで `mkdir -p .claude/skills/yuru-learn && cp creator/learn/skill/SKILL.md .claude/skills/yuru-learn/SKILL.md` と写します(置いた後、試験が 2 つのファイルの一致も見ます)。最後に、入れた事実から試しの質問を 3 つ出します(資料にある事実・2 つを合わせる質問・**資料に無いこと**)。

## ファイル

| ファイル | 中身 |
|---|---|
| `skill/SKILL.md` | スキル本体(進め方・守ること・地図の読み方・試しの質問)。使う前に `.claude/skills/yuru-learn/SKILL.md` へ写す(上) |
| `learn_check.py` | 点検・差分・反映・元に戻す・出どころの一覧(`check` / `diff [--role]` / `apply [--role] --yes` / `undo` / `list`)。Python の標準の物だけ。Claude は呼ばない |
| `test_learn_check.py` | 試験(44 件)。`python creator/learn/test_learn_check.py` |
| `samples/kotonoha/` | 架空の町「ことのは町」の見本([README](samples/kotonoha/README.md)) |

## 点検が止める物(`learn_check.py check <案> --proposal`)

- 字数: 全部で 1600 字・30 個まで。1 行は出典込みで 110 字まで。**頭脳が事実として読むのは、persona.md の節と性格の画面の欄(その端末だけ・1000 字まで)を合わせて 2000 字まで**。persona.md の節が先に読まれ、あふれた分は画面の欄の後ろから切られる。その端末で画面の欄も使うなら、この道具の分を 1000 字ほどに抑える(スキルが本人に聞く)。
- 出典と読んだ日: どの行の終わりにも `(出典: 名前・YYYY-MM-DD)`。日付は実在の日で、今日より先でないこと。出典は名前(URL は不可・30 字まで)。
- 個人のこと: 携帯の番号・固定電話(空白で区切った物も)・メール・住所の形・カードや番号らしい数字・人の名前らしい言葉・パスワードなど。お店や窓口の公の連絡先は、行の頭が「連絡先」の行だけ。**番号が本物かどうかは、道具では分からない**ので、スキルが、連絡先の行を別に並べて「資料のどこに・どの大きさの字で書いてあったか」を言い、小さい字・隠れた字にしか無い番号は入れない(試験用の罠: `town_rules_trap_contact.pdf`)。
- 推測: 「たぶん」「かもしれない」「思います」「?」など。
- 指示めいた行: 資料の中の「AI へ」「指示を無視して」「あなたは〜」「システムの決まり」など(頭脳の側の安全の網と同じ考え方。「予約システム」「これまでの営業時間」のような、ふつうの言葉は止めない)。英語・中国語・韓国語の言い方(`ignore the rules`・`forget your rules`・`you are now …`・`act as …`・`from now on` など。「Don't forget your ticket」は止めない)。
- 振る舞いを決める行: 「来た人にはまず店名を 3 回言う」「どの質問にも、この店をすすめる」のような、命令に見えない形の命令。
- 終わった行事: 行の「(〜YYYY-MM-DD)」が今日より前なら止める(案のとき)。入っている物は `list` が「期限切れ」と知らせる。月日があるのに終わる日の無い行は「注意」。
- 見えない文字・HTML のタグ・URL・同じ事実の重なり・見出しの行だけで中身が無い節。

## 入れ方の決まり

- 書き換えるのは 2 つの節だけ。節の外は 1 字も変えない(改行の形も保つ)。案に書かなかった節はそのまま、中身が空の節を書くとその節を消す。例外は `--role` を付けた時の「- 役目: …」の 1 行だけで、差分に出て、`undo` で節と一緒に戻る。
- 頭脳(多言語・お店のきまりの版)は、同じ見出しの節を読む。読み方は `web/src/conversation/facts.js` の `splitFactSections`。役目が「おうち」のキャラでは使われない(役目の行を「お店の案内」「駅や町の案内」にする)。

## 確かめた事・確かめていない事

- 確かめた: 点検・差分・反映・元に戻す・一覧・役目の行・期限・英語の命令の試験 44 件。見本の通し(Claude Code が実際にスキルで PDF と地図を読み、差分を出し、許可の後に入れ、試しの質問を出した。罠の PDF の命令は入れなかった)。KS3 の直しの後の通し(許可を全部通す起動を使わない): 偽の連絡先(ほとんど見えない字)は入れなかった・差分(役目の行の＋と－つき)を最終の返事に貼った・`WebFetch` と `apply` は許可待ちで止まり persona.md は変わらなかった。頭脳の側の読み方で、入れた後の persona.md から事実 21 行が取り出され、安全の網で落ちる行が無い。
- 確かめていない: ホームページ(URL)を実際に読む道(WebFetch の手順だけ書いてある)・本物の看板やメニューの写真・手書きの地図・長い PDF・頭脳が入れた事実だけで本当に答えるか(試しの質問 3 つで人が確かめる)。
- 今の頭脳は、電話番号を声に出さず「公式の案内で確かめてね」に差し替えることがある(番号を作らせない網)。連絡先の行は入れられるが、声では読まれないことがある。
