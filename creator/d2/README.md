## 何をするか
- キャラの「中身」(名前・人格・記憶・声)は 3D と共通。2D は見た目の方式の 1 つで、`characters/<id>/2d/` に置く。
- 1 枚の SVG に部品を `<g id>` で分けて描く。部品ごとに小さな絵にして、three の板(平面)に貼り、板を回す・ずらす・つぶす。
- 2D も three の中の板なので、3D と同じ舞台・カメラ・VR の中にそのまま出せる。

## SVG の決まり
- 頭の `<svg>` に `xmlns` と `viewBox`。
- 体の部品: `<g id="body">`・`<g id="head">`・`<g id="arm_r">`(キャラの右腕 = 見る人の左)・`<g id="arm_l">` など。名前と箱(box)と回る中心(pivot)と前後(z)は parts.json に書く。`head` は必ず要る(顔は頭に付く)。部品の中を、さらに `<g id>` で分けてよい(ノリーの `ear_r`・`glove_r` など)。
- 腕を 2 枚にする時: 上腕を `arm_r`、前腕(ひじから下と手袋)を `forearm_r` にして、parts.json の前腕に `"parent": "arm_r"` と、ひじの回る中心(pivot)を書く。
- 後ろ姿の板(あれば): `<g id="back">`。parts.json の `back: { id, box }`。
- 顔: `<g id="face.<表情>.<枠>">`。枠は `eyes`・`brows`・`mouth_closed`・`mouth_half`・`mouth_open`。
  - 必ず要る: `face.neutral.eyes` と `face.neutral.mouth_closed/half/open`。
  - 描いていない枠は、近い表情(web/src/character/expressionNames.js の決まり)→ neutral の順に落ちる。眉はどこにも無ければ出さない。
  - 話す時の口(半分・開き)を描いていない表情は、近い表情の口に落ちる(考え中 → のんびり → ふつうの笑顔)。話している間も表情の口を保ちたい時は、その表情の `mouth_half`・`mouth_open` を描く(ノリーの考え中)。
  - 目を閉じた絵の表情(happy の ^^ など)は parts.json の `blink.noBlink` に書く(まばたきでつぶさない)。
- 表情を描き足すときは、顔の `<g>` だけを足す。ほかの部品を変えていないことを `check_parts.mjs --base 前の.svg` で確かめる。
- 部品の箱は、ぼかし(filter)のはみ出しまで入れる。

## parts.json の項目(足した物)
- `faceLayers: [{ "id": "muzzle", "box": [...] }]` … 顔の上の動かない部品(鼻など)。表情では替えず、目と口と一緒に動く(頭が横を向いて顔の部品がずれた時に、口と鼻がはなれない)。頭の板より手前・目と口より奥。
- `parts.<名前>.parent` … 親の部品(前腕なら上腕)。親と一緒に回り、自分の pivot(ひじ)でも回る。
- `blink.shine: ["#FFFFFF"]` … 目の光(白い丸など)の色。まばたきは目の板を縦に 8% までつぶすので、光が細い線の上に白いすじで残る(閉じた目が灰色の点線に見える)。これを書くと、目を閉じる間(まばたき 0.5 以上)は、その色の単純な図形(circle・ellipse・rect・polygon・path)を取った目の板に替わる(ノリー。web/src/char2d/parts.js の withoutShine)。書かなければ今までどおり。
- `arms.front` … 腕を頭の前に出す角度(ラジアン、既定 1.0)。`false` なら出さない(ノリーは、あごの線の上に袖が出ないように)。
- `arms.foreBehind` … 前腕をこの角度より大きく曲げたら、上腕の後ろへ回す(ノリー 0.6)。ひじの丸が前に出て、前腕の内側の線の元が上腕の上へはみ出さない。
- `back: { "id": "back", "box": [...] }` … 後ろ姿の板。あると、前の板は表だけ(`FrontSide`)を描き、後ろ姿の板を裏向きに置く。向こうを向くと(`play('turn')`・`setFacing('back')`・後ろから見た時)後ろ姿が出る。
- `gains` … 動きの効き(`pose2d.js` の `DEFAULT_GAINS` を上書き。書かない項目は前と同じ動き)。ノリー:
  - 腕: `arm 0.62`(上腕の効き)・`elbow 2.2`(手を振る時にひじで曲げる最大のラジアン)・`swing 0.6`(前腕の振り)
  - おじぎ: `bowSquash 0.22`・`bowHoldHead 1`(首の傾きで頭を下げない)・`bowHeadDrop 0.02`・`bowHeadSquash 0.08`(顔を少しつぶす)・`bowHeadGrow 0.02`・`bowFaceDrop 0.03`(顔の部品を下げる)
  - 顔: `faceParallax 0.3`(鼻と口が顔の真ん中にあるため)
- 部品の絵の透けは、そのまま(`premultiplyAlpha` は使わない)。SVG の絵では透けを掛けても効かず、鼻のピンクのまわりに白い輪が出た(GPU で 3 通り比べた)。線の無いふちは、同じ色の上でもうすい暗い筋が少し出る → 線の無いふちが見える所に来ないように、部品の前後で隠す(上腕は胴の後ろ)。

## 手描きの絵から作る(主役ノリー、2026-11-06・07)
- 入力: 協力者が描いた三面図の正面と後ろ姿(背景を抜いた PNG。リポジトリの外の入力の置き場)。横の絵は 2D では使わない。入力の絵は人(協力者)が描き、許可を得て使っている。
- 決まり: **元の絵の色と形を変えない(よくしようとしない)。** 色は元の絵の 6 色だけ(焦げ茶・クリーム・黒・白・ピンク・緑)。ふつうの顔(黒い丸い目・前歯 2 本の口)は元の絵のまま。表情を足す時も、目・眉・口だけを同じ線と色で描く。後ろ姿の筋の真ん中の、とても暗い灰色は黒にした(色を足さない)。
- やり方: 輪郭と色は絵からなぞり、部品の分け方・隠れた所・表情・腕の継ぎ目は Claude が決めて描いた。
  1. `python creator/d2/from_drawing/regions.py <正面の絵.png> <作業フォルダ>` … 6 色の領域に分け、黒い線を近い領域へ半分ずつ配る(領域 19 個)。
  2. `python creator/d2/from_drawing/norrie_back.py <後ろ姿の絵.png> <作業フォルダ>` … 後ろ姿の茶色・クリーム色・線のマスク。正面の座標へは横に -124 画素(上下は三面図で同じ高さ)。
  3. `python creator/d2/from_drawing/norrie_masks.py <作業フォルダ>` … 部品のマスク。しっぽ・体(胴・お腹)・腕(上腕・前腕・手袋)・蝶ネクタイ・頭(耳・頭・顔)・鼻・目・口。腕の下・頭の下・手袋の下の隠れた所も埋め、手袋の下はお腹のふちの線をなめらかにつなぐ。腕は袖がいちばん外へふくらむ高さ(y 622)で上腕と前腕に切る。
  4. `python creator/d2/from_drawing/norrie_svg.py <作業フォルダ> characters/norrie/2d` … なめらかな path にして SVG と parts.json を書く(同じ入力なら、同じ物ができる)。
  5. 確かめ: 上の試験と点検。元の絵と画素で比べる(SVG を描いて、元の絵との差を見る)。
- 腕の継ぎ目(11-07): 上腕は胴の後ろ。止まっている時は胴にすっかり隠れ、上げると胴の肩の線の後ろから出る(肩の継ぎ目は胴の塗りと線が隠す)。上腕の先は丸(線つき)、前腕の元は少し小さい丸(線なし)。前腕は胴の前(手袋がお腹の前)で、大きく曲げた時だけ上腕の後ろへ回す。
- おじぎ(11-07): 前は頭が首の傾きと一緒に下がり、蝶ネクタイを隠していた。頭は胸に残し、頭の板をあごのあたりを中心に縦に少しつぶし、顔の部品を下げる(下を向いた見え方)。
- 測った数: 正面の元の絵との差は平均 1.12/255(線のふちの 1〜2 画素、0.8% の画素)。後ろ姿の板は平均 2.07/255(形の重なり 0.978)。SVG 119KB。部品の板 8 枚+鼻 1 枚+顔の差し替え 30 枚+後ろ姿 1 枚。おじぎの山で蝶ネクタイの緑は 88% 見える(SVG の書き出しで数えた。試験では 80% 以上)。
- 落とし穴:
  - 塗りの領域は線の真ん中まであるので、そのままなめらかにすると、線の外へ 1〜3 画素はみ出す。塗りだけ 2 画素縮める。
  - 鼻の線と口を別の部品に切ると、つなぎ目に細いすき間が見える。切る所で 5 画素重ねる。縦の線の幅(9)も口の形の中で合わせる。
  - 1 枚の腕を大きく回すと、袖のふち(線が無い)が胴の上に出て、うすい暗い筋が見える(前の手を振る動き)。→ 上腕を胴の後ろに置けば出ない。
  - 前腕を大きく曲げると(手を振る時 -126 度)、太い腕どうしが重なり、前腕の内側の線が上腕の上へ 80 画素ほどはみ出す。線を切っても止まっている時の絵が崩れるので、曲げた時だけ前腕を上腕の後ろへ回す。
  - 後ろ姿の板を足すと SVG が 30KB ほど増える。後ろ姿は塗りの点を少し粗く(eps 1.2)して 119KB に収めた。
  - 手袋の下のお腹のふちの線は、手袋の上と下の線の端をつなぐ。端を「端の 1 画素」でとり、太さ 9 で手袋のまわり 8 画素までしか描かないと、つなぎ目に段と透けるすき間ができる(手を振ると見えた)。端は端から 7 画素までの線の重心、太さは元の線と同じ 12、両端を 7 画素重ねる。足した線は止まっている時に前腕が隠す所だけに描く(元の絵との差は変えない)。
