# a7 + iPhone の校正の手順(本人 1 人で約 15 分)

LED の前で、**一続きの撮影 1 本**で「レンズの歪み」「iPhone と a7 のずれ」「2 台の時刻合わせ」が全部取れる。撮り終わったら PC で計算するだけ。

## 前もって(ショー担当 / PC)
- LED の映像の**先頭と末尾の 2 か所**に、`LEDに出す物/同期のフラッシュ_5680x1240.mov`(白いフラッシュ 6 回・12 秒)を 1 回ずつ入れる。**2 か所あって初めて時計の進みの差(alpha)が正しく出る**(1 か所だけだと 1.0 から大きくずれる。その場合は alpha=1 に固定)。
- 校正の間に流す映像: `LEDに出す物/盤_A面_5680x1240.mov`(または `_H264.mp4`、60 秒。盤は **x 0〜956 の A 面だけ**に収めてあり、中央の面には出ない。残りは黒)。**LED の明るさは 50% ほど**(白が強すぎると角がにじむ)。

## a7 の設定(撮影の前に 1 回)
- 動画 4K(30p か 29.97p)。**手ぶれ補正は切**(SteadyShot 切、レンズ内も)。
- **レンズ補正の「歪曲収差補正」**: 切れるなら切。**切れない(切れないレンズの可能性が高い)ときは、そのままでよい**: 校正は「撮れた映像に残っている歪み」を測る。**校正と本番で、a7 とレンズの設定をまったく同じにする**(ここが変わると校正が使えない)。
- **ズームを撮影本番で使う位置に固定**し(テープで止める)、**ピントはマニュアルで固定**。校正のあいだ、ズームもピントも動かさない。
- iPhone を a7 の上に動かないようにしっかり付ける。**撮影のあいだ、2 台の位置関係を変えない**(これが「固定のずれ」)。

## 15 分の流れ
1. **(2 分)iPhone「撮影記録」**: 右上で「LED 3面」、必要なら「露出・色・ピント固定」を入れ、床 → A・B・C の 4 隅ずつを記録(12 回)。LED は黒でも盤でもよい。
2. **(1 分)** LED の映像を「盤」にする。a7 の録画を開始し、iPhone の「● 録画開始」。
3. **(1 分)最初のフラッシュ**を流す(同期用。映像の先頭の 12 秒)。そのあいだカメラは動かさない。
4. **(5 分)撮る**: 盤が両方のカメラに写るまま、台を持って **8 か所ほど、少しずつ位置と向きを変えて 2 秒ずつ完全に止まる**。
   - 止まる所では、盤が画面の中央・四隅・左右の端・上下の端に来るように。近くと遠くも。
   - 動くあいだはゆっくり。止まる 2 秒だけが「ずれ」の計算に使われる。動いているあいだも「歪み」の計算に使われる。
5. **(1 分)最後のフラッシュ**を流す。カメラは動かさない(時計の進みの差が測れる)。
6. **(1 分)** 2 台とも止める。iPhone は「共有(AirDrop)」で Mac へ。a7 のカード(または HDMI の録画)から動画を PC へ。

## PC で計算(撮影のあと。数分)
```
SHOOTLOG_DEST=J:/…/shoots python place/shootlog/receive_shoot.py                          # iPhone の記録を取りこむ
python place/shootlog/sync_flash.py --a <a7の動画> [--a-window 開始秒 終了秒(長い動画で、フラッシュのある区間だけ読む)] --b <iPhoneの video.mov> --b-shoot <iPhoneの撮影フォルダ> --out sync.json
python place/shootlog/lens_calib.py --video <a7の動画> --board board_A.json --out-dir lens/ --focal-mm35 <使ったズームの mm>
python place/shootlog/rig_offset.py --a7-video <a7の動画> --lens lens/lens.json --iphone-shoot <iPhoneの撮影フォルダ> --board board_A.json --sync sync.json --out-dir rig/
```
- 本番の撮影のあとは、同じ iPhone の記録から a7 のカメラの動きを UE 用の CSV にする:
```
python place/shootlog/export_a7_ue.py --iphone-shoot <本番の撮影フォルダ> --alignment rig/alignment_board.json --rig rig/rig_offset.json --lens lens/lens.json --sync <本番のsync.json> --a7-fps 29.97 --a7-frames <a7のコマ数> --ue-origin X Y Z --ue-yaw 度 --out camera_track_a7_ue.csv
python place/shootlog/apply_distortion.py lens/ <CGの画像または動画> <歪みをかけた出力>    # 歪みは直さない: CG に a7 と同じ歪みをかける
```
- 本番の動画にも、先頭と末尾のフラッシュを入れておけば `sync_flash.py` で本番の時刻合わせができる。

## 数字の見方(合格の目安)
- `lens_calib`: `rms_reprojection_px` が 0.5 以下、`holdout_rms_px`(半分の構図で解いて残りで確かめた値)も同じくらい。`coverage.png` で、盤の角が画面の端まで届いているか。
- `sync_flash`: 残差が a7 の 1 コマ(33 ms)より小さい。
- `rig_offset`: 「ばらつき」が数 mm、向きが 0.2° 以下。使えた止まっている所が 5 個以上。
- 合成データでの確かめ: 歪みの係数が真の値に 0.4 px 以内、同期の誤差 15 ms、ずれは位置 7 mm・向き 0.05°。実機の a7 での値は撮影後に確かめる。
