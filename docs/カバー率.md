## 「確認済み」の意味

- **オリジナルのキャラ**(実在のキャラには似せない)を、**スキルだけを読んだ作業役**が作り、**固定の試験**に合格した物だけ。結果表(`creator/skilltest/結果表.md`)の行と結びつけます。
- 「作れるはず」は数えません。「未確認」と書きます。
- 固定の試験(①〜⑦): ① builder が通る ② 輪郭の重なり 0.90 以上、中心のずれ・外接箱の差が小さい ③ 色・質感・顔の部品が出ている ④ 骨+動き 3 つ以上+シェイプキー ⑤ 一覧を見て 2 周直す ⑥ 方向を変えて崩れなし ⑦ ブラウザで再生できる(`pk02_check_character.py` が OK、viewer で動きと表情が動く)。判定は、作った担当とは別の文脈の Claude(Haiku 5.5 と Sonnet 5.5)と、私の実測。

1. **見る人が見るブラウザ(three.js、creator/viewer)で撮った絵**を、元の絵と並べて、別の文脈の Claude 2 つ(Haiku 5.5 と Sonnet 5.5)に同じ問い「毛足・布(ぬいぐるみ)の質感が出ているか」「色は元の絵に近いか」を聞き、**どちらも両方が「はい」**(各 3 回、2 回以上はいでその判定役のはい)。Blender の絵だけの合格は数えない。

3. 質感を出す技(毛足の画像、毛の殻など)が、スキルに手順として書かれ、**スキルだけを読んだ作業役**が再現している。

## 数字の信頼と限界

- **判定役は Claude だけです**(Haiku 5.5 と Sonnet 5.5。新しい文脈、各 3 回、1 語)。**同じ系統の判定役 2 つなので、独立した 2 人とは言えません**(見方が似て、同じ間違いをするかもしれません)。作った担当(Claude)とも同じ系統です。そこで、数字のほかに、使う人の目と、実測(輪郭の重なり、検査)を優先します。
- **判定役が割れることがあります。** 毛足は s_flower で Haiku 3/3・Sonnet 0/3、部分は t_cape のマントと v_happi の胸の文字で Haiku 3/3・Sonnet 0/3 でした。Sonnet 5.5 は、毛足と部分の問いに一度も「はい」を出していません(Haiku が甘いのか、Sonnet が厳しいのかは、決められていません)。決まりどおり、**両方「はい」でないものは数えません。**
- 絵が残っていない題材(固定の試験の 1〜8 段、d_lantern・f_led、Megascans の look など)は、Claude の判定が「未」です。撮り直しには GPU が要るので、していません。
- 同じ絵を 2 回流して、判定のぶれを測ることは、していません(未確認)。
- 試した題材は 14 体(オリジナルのキャラ)で、数が少ないです。「全国のキャラの何割」とは言えません。以前は全国のキャラの分類との割合を出していましたが、分類は Claude 以外の判定で、元の一覧の絵も手元に無く取り直せないので、**数字ごとやめました。**
