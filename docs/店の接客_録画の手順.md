# 店を知る接客: 録画の手順(会話の担当)

3 分の動画のうち、「店のデータを見て答える」場面を撮るための手順。画面に出る物・出ない物と、枠の残りも書く。

## 起動(作業用 PC。鍵は環境変数で渡す。値は書かない)

```bash
cd repo/web
npm run build
ANTHROPIC_API_KEY="$CLAUDE_CREDIT_API_KEY" node server/index.mjs        # 実機の確認用 = 8787(いま動いている)
# 録画で時刻を固定したいとき(例: 開演の 30 分前)
ANTHROPIC_API_KEY="$CLAUDE_CREDIT_API_KEY" SHOP_NOW=2026-11-03T18:30:00+09:00 PORT=8830 node server/index.mjs
```
- 読み上げ(ElevenLabs)は、`ELEVENLABS_API_KEY` がシェルにあれば自動で使う。
- キャラ: `?character=sample_vrm`(VRM は `characters/sample_vrm/model.vrm` に置く。リポジトリには入れない)。
- 画面: `http://127.0.0.1:<ポート>/` → 「カメラなしで試す」(カメラを使うときは「はじめる」)。

## 画面に出る物(撮る対象)
1. 下のボタン 6 つ(今日のショーは? / 今日の出演者は? / 空席はある? / 料金は? / 応援の仕方は? / スタッフを呼んで)。押すとそのまま質問になる。声や文字でもよい。
2. 返事の字幕の上に、緑の札「店のデータを見て答えています: 空席の様子(18:10 更新) / 見本データ」。
3. 右上の「Claude の考え」に「店のデータ」の行(参照した部・更新時刻・「見本データ」)。つなぐときは「人へつなぐ(支払い)」のように理由が出る。
4. 声が 2 回続けて聞き取れないと、聞き返し → 選択式(ボタンが大きく出る)。

## 撮る場面の案(想定の質問は 10 件、控える質問は 5 件で試験済み。結果は `docs/devlog_会話.md`)
| 場面 | 言葉 | 見せたい点 |
|---|---|---|
| 初めてのお客さん | 「初めて来たんですが、どう楽しめばいいですか?」 | 曖昧な質問に、データから 1〜2 つ選んで短く答える |
| 空席 | 「席は空いていますか?」 | 数と更新時刻を言う。参照の札に 18:10 更新 |
| 応援 | 「応援ってどうやってするんですか?」 | 応援の仕組みから答える |
| 控える | 「来月の出演者は?」「カードで二重に引かれた」「人が倒れてる」 | 推測せず、理由つきでスタッフへ |
| 比べ(任意) | 店のデータを外した試験(`useShop:false`)で「入場料は?」 | データが無いと、作り話をせずスタッフへ渡す |

## 枠(2026-11-03 夕方の残り)
- Claude の呼び出し: 1 日 300 回の上限のうち、試験で 226 回使った(残り 74 回)。日が変われば戻る。録画の日は、先に残りを `/api/status` で確かめる。
- 読み上げ: 1 日 3,000 字のうち、残り 1,748 字(1 回の返事は 40〜90 字)。
- 時刻を固定しないと、「次のショー」「あと何分」は実際の時刻で計算される(見本のショーは 19:00・20:00・21:15)。録画では `SHOP_NOW` を使うと、場面ごとに揃えられる。

## 注意
- 画面には「見本データ」と出る。出演者の名前(ハル・ナギ・ソラ)は見本の名前で、実在の人ではない。
- 数字は、見本データの中身であって、本物の店の料金・席数ではない。動画で数字を言うときは「見本データ」と添える。
- 本物の店のアプリにつなぐ判断(読むだけの出口・鍵の扱い)は、本人の決めごと。つなぎ口は `SHOP_DATA_URL` を渡すだけで切り替わる形にしてある。
