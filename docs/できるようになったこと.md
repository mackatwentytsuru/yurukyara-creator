# できるようになったこと

新しい版でできるようになったことを、新しい順に 1 行ずつ書きます。
アップデートのしかたは [README の「アップデートのしかた」](../README.md#updating) にあります。あなたのキャラ・性格・声・記憶・設定は消えません。

     版の文字は、リポジトリの頭の VERSION と同じにする(tools/yuru_update.py が、この見出しで前の版との間の行を選ぶ)。 -->

## 1.0.0(2026-11-08)

- ノリーと話せます。3D と 2D を、ボタンで切り替えられます。
- 鍵が無くても、文字とレトロな音で話せます。
- 話したことを覚えます。「わすれて」と言うと、全部消えます。
- 6 けたの番号で、別のブラウザのタブへ、話の続きを運べます。
- 性格・口調・元気さ・返事の長さ・声の役(おまかせ・男の子・女の子)を、画面で選べます。
- 自分の PC と Claude Code で、言葉か 1 枚の絵から、自分のゆるキャラの絵を作れます。直したい所は一言で頼めます。
- 「アップデートして」と言うと、キャラを消さずに新しい版にできます。前の版に戻すこともできます。
