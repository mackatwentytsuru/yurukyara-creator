## キャラの渡し方

`characters/<id>/character.json`

```json
{
  "id": "example",
  "name": "表示の名前",
  "model": "model.vrm",
  "type": "vrm",
  "height_m": 1.2,
  "expressions": ["neutral", "happy", "surprised", "sad", "thinking"],
  "motions": { "bow": "motions/bow.glb", "wave": "motions/wave.glb" },
  "persona": "persona.md"
}
```

- `type` は `vrm` か `rig`。`rig` は人型の骨でないキャラで、GLB の骨とシェイプキーで動きます。
- `rig` のキャラは、`character.json` に `look`(視線に使う骨か形)と `mouth`(口の開きに使う形か骨)を書きます。名前の細かい形は、キャラの柱が決めて、ここに書き足します。
- 動きは 30fps。

### 表情の名前

名前は英語の短い識別子(camelCase)にそろえます。どの表情も 0〜1 の重み 1 つで動き、まばたき(`blink`)とは別物です。`character.json` の `expressions` には、そのキャラの VRM に入っている名前を書きます。

- **標準**(VRM 1.0 のプリセット): `neutral` `happy` `angry` `sad` `relaxed` `surprised` / 口 `aa` `ih` `ou` `ee` `oh` / まばたき `blink` `blinkLeft` `blinkRight` / 視線 `lookUp` `lookDown` `lookLeft` `lookRight`
- **カスタム**(アニメ版見本のキャラ v5b。使い方の日本語つきの正本は `export_vrm/v5_expressions.json`): `wink` `winkRight` `shy` `bigSmile` `pout` `troubled` `cry` `smug` `sparkle` `mouthO` `thinking` `tongue` `singBig`
- `think` は `thinking` の別名として受けます(読み込み側で `thinking` に読み替える)。新しく書くときは `thinking`。
- **VRM に無い名前は、近い標準の表情に落とします**: `wink` `winkRight` `shy` `bigSmile` `smug` `sparkle` `tongue` → `happy` / `pout` → `angry` / `troubled` `cry` → `sad` / `mouthO` → `surprised` / `thinking` → `neutral` / `singBig` → `aa`。知らない名前は何もしない(エラーにしない)。
- **重ね方**: 特別な表情(カスタム)は同時に 1 つ+標準の表情まで。頬の ///・涙・汗・眉・瞳の星(漫符)は値に比例して大きくなる小さな板なので、`shy` `cry` `troubled` `pout` `sparkle` `bigSmile` は **1.0 で使い**、漫符を持つ表情どうしは重ねません(漫符が飛び出す)。会話の画面は、特別な表情が強いあいだ `blink` を 7 割弱めます。
- 名前や使い方を増やすのはキャラの柱で、ここに書き足します。

`web/` は、どちらの `type` も同じ呼び方で動かします。

```js
const character = await loadCharacter(url);
character.object3d;              // シーンに入れる
character.lookAt(worldPosition); // 目が先、首が後
character.setExpression(name, weight);
character.setMouth(level);       // 0〜1
character.play(motionName);
character.update(dt);
```

## 場所の渡し方

`places/<id>/place.json`

```json
{
  "id": "example",
  "name": "表示の名前",
  "model": "room.glb",
  "scale_m": 1.0,
  "floor_y": 0.0,
  "spawn": { "position": [0, 0, 0], "yaw_deg": 0 },
  "landmarks": [
    { "name": "入口", "position": [0, 0, 2], "note": "案内に使う説明" }
  ]
}
```

- 単位はメートル、y が上、右手系。
- `landmarks` は Claude に渡して案内に使います。キャラが実際の方向を見たり指したりします。
- `variants` は任意です。見た目の名前と GLB の組を書きます(例 `{"raw": "room.glb", "stylized": "room_stylized.glb"}`)。`loadPlace(url, {variant})` と `?variant=` で切りかえます。

```js
const place = await loadPlace(url);
place.object3d;
place.spawn;
place.landmarks;
```

`place/` は `loadPlace` を `place/web/` から出し、`web/` はそれを読み込みます。

## 見せ方の 3 つ

同じページで切りかえます: `screen`(ふつうの画面)/`ar`(スマホで現実に重ねる)/`vr`(Quest 3)。入口は `web/`、AR と VR の部分は `place/web/` が作ります。

## 全員の決まり

- **新しく書きます。** 2026-11-02 12:30 より前のコードと物は、コピーも土台にもしません。読むのは、知識として必要なときだけです。

- コミットは小さく、日本語で。自分のフォルダだけを `git add <フォルダ>` してコミットします。全部を一度に足す `git add -A` は使いません。push はしません。
- うまくいかなかった試しも `docs/devlog_<柱>.md` に 1 行ずつ残します。数字は測った物だけ書きます。
