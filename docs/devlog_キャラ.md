# 開発の記録: キャラの柱(ゆるキャラクリエイター)

流れ: ゆるキャラの絵 1 枚 → 顔なしの絵(Codex) → 3D の形(TRELLIS.2) → 整える(Blender) → 色(自分の絵から) → 骨と重み → 動き → 顔の表 → ブラウザ。
各段の出来は Claude が見て、足りなければ前の段をやり直す。うまくいかなかった試しも残す。数字は測った物だけ。

## 2026-11-02(夜)

- 前の作業が止まった状態から続けた。`creator/pipeline/` の段 1・3・5 は未コミットだったので、読んで直してからコミットした。
  - 段 3(TRELLIS)は起動に失敗していた(`SRE module mismatch`)。呼び出し元の Python の環境変数(PYTHONHOME など)が、別の版の標準ライブラリを読ませていた。子の起動から環境変数を除いたら、12〜34 秒で上がった。
  - 段 5 には、使っていない未実装の関数(NotImplementedError)が残っていたので消した。
- 入力は `f_led`(LED パネル)と `d_lantern`(提灯、足なし)。人型でないので、VRM の骨には合わせず、`type: "rig"` の独自の骨にする。
- 顔なしの絵は Codex(`codex_dual.py`)で 2 枚とも 1 回で作れた(40 秒・58 秒)。
  - LED は、光る点だけを消して画面を消灯した形にできた。提灯は、目・口・ほおを消して紙の色で埋められた。
  - 注意: 顔なしにすると、手足や体の比率が元の絵と少し変わる。顔の位置は元の絵ではなく、顔なしの絵で測り直す。
