# Rights to the character data / キャラのデータの権利

The characters in this folder (3D data, 2D parts, pictures and personality texts) are **not licensed for reuse**. They are here to test the app and to show this work.
Make your own characters from your own pictures (`.claude/skills/talking-character/`).

- `norrie` (Norrie): a collaborator drew the design by hand during the hackathon (front, side and back) and let us use it. The drawing itself is not stored in this repository. Claude Code made the 2D parts and the 3D model from it.
- `yokoso`, `robo`, `f_led`, `d_lantern`: Claude drew the original pictures as SVG during the hackathon (`creator/samples/<id>_元の絵.svg`) and built the 3D models from them with Blender's Python.
- `mikan`: Claude drew the picture from words during the hackathon (`creator/samples/mikan_元の絵.svg`) and built the 3D model from it.
- `_test`: a small character used only by the checks.

このフォルダのキャラ(3D のデータ・2D の部品・絵・性格の文)は、**再利用を許可しません**。動作の確かめと、この作品のデモのために置いています。
自分のキャラは、自分の絵から作ってください(`.claude/skills/talking-character/`)。

- `norrie`(ノリー): 協力者がハッカソンの期間中に手で描いた絵(正面・横・後ろ)を、許可を得て使っています。絵そのものは、このリポジトリに入れていません。2D の部品と 3D は、この絵から Claude Code が作りました。
- `yokoso`・`robo`・`f_led`・`d_lantern`: 元の絵は、期間中に Claude が SVG で描きました(`creator/samples/<id>_元の絵.svg`)。3D は、その絵から Claude が Blender の Python で組みました。
- `mikan`: 期間中に Claude が言葉から絵を描き(`creator/samples/mikan_元の絵.svg`)、その絵から 3D を組みました。
- `_test`: 点検だけに使う小さな試しのキャラです。
