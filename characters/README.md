# キャラのデータの権利

このフォルダのキャラ(3D のデータ・絵・性格の文)は、コードと違い、**再利用を許可しません**。動作の確かめと、この作品のデモのために置いています。
自分のキャラは、自分の絵から作ってください(`.claude/skills/talking-character/`)。

- `yokoso`: 元の絵(`creator/samples/yokoso_元の絵.png`)は、開発期間中に画像の AI で作ったオリジナルです。3D は Claude が Blender の Python で組みました。
- `robo`: 元の絵(`creator/samples/robo_元の絵.png`)は、開発期間中に画像の AI で作ったオリジナルです。3D は、新しい写しのリポジトリで Claude がスキルだけで組みました(人の手なし)。
- `f_led`・`d_lantern`: 開発期間中に作ったオリジナルです。
