# 見本のキャラの記憶の作り

記憶を 4 つに分ける。**変わる速さと、間違えたときの怖さが違う**ため。

| 層 | 中身 | 置き場所 | 更新 |
|---|---|---|---|
| 1. 店の事実(店の記憶) | 営業時間・料金・席と予約・行き方・ルール・飲食・応援の仕方・雰囲気・連絡先・貸切。**1 つずつ出どころ(URL か名前)・取得日・確度・変わりやすさ**が付く | `venue.json`(見本: `sample/`、本物: `private/`) | 調べ直したら差し替える |
| 2. 今日のデータ | 今日のショー・出演者・空席。**更新時刻が必須**。無ければ推測せず「スタッフに」 | `web/server/shop/`(いまは見本、本物は URL で差し替え) | 毎日・毎分 |
| 3. 見本のキャラの設定と話し方 | 名前・見た目・口ぐせ・話してよいこと/いけないこと | `characters/sample_vrm/persona.md` | 作り手が直す |
| 4. 知らないときの答え方 | 推測しない・スタッフにつなぐ理由・話題の外・決まりを話さない | `.claude/skills/shop-guide/SKILL.md` の rules 部分(実行時にそのまま頭脳へ) | 試験で直す |

## 事実の形(`venue.json`)

```json
{ "id": "f001", "category": "料金", "fact": "入場料は 2,000 円です。",
  "sourceLabel": "公式サイト", "sourceUrl": "https://…", "fetchedAt": "2026-11-04", "infoDate": "2026-10",
  "volatility": "fixed | seasonal | daily", "confidence": "high | medium | low", "note": "" }
```

- 分類は 13 個: 営業時間・定休日 / 料金 / 席・予約 / イベント・ショー / 出演者の出し方 / 応援の仕方 / 行き方 / 禁止事項・ルール / 飲食 / よくある質問 / 雰囲気 / 運営・連絡先 / 貸切・イベント利用。
- **取得日の無い事実は使わない**(いつの情報か言えないため)。見つからなかった分類は `"fact": null` で残す → 聞かれたら推測せずスタッフへ。
- 確度が低い・古い物は、頭脳に「断定せず、公開されている情報では…と言い、スタッフにも確かめるよう添える」と渡す。画面の参照の札にも注意の印が出る。
- 今日のデータと食い違うときは、今日のデータを優先する。

## 公開と非公開

- 公開のリポジトリに入れる: 形・読み込み・試験・**見本**(架空の店「ショーのある新しい店」)。
- 入れない(`.gitignore`): 本物の店の事実(`private/`)と、それで試した結果(`eval/results/private_*`)。実名・出どころの URL・インスタの内容を含むため。
- 演者の名前・顔は、同意のある物だけ。同意の記録が無い人は記憶に入れない。
